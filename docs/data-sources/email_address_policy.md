# msexchangeonline_email_address_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_email_address_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/email_address_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_email_address_policy" "default" {
  name = "Default Policy"
}

output "enabled_email_address_templates" {
  description = "The address templates of the default email address policy."
  value       = data.msexchangeonline_email_address_policy.default.enabled_email_address_templates
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `enabled_email_address_templates` (List of String) SMTP address templates (e.g. `SMTP:%g.%s@contoso.com`). The primary address uses `SMTP:` (uppercase).
- `id` (String) The unique identifier of the email address policy.
- `priority` (Number) Priority of the policy. Lower numbers take precedence. The default policy always comes last and reads as `0`.

## Permissions

The provider's app registration needs the **E-Mail Address Policies** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
