# msexchangeonline_hosted_content_filter_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_hosted_content_filter_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/hosted_content_filter_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_hosted_content_filter_policy" "default" {
  name = "Default"
}

output "spam_action" {
  description = "Action taken on spam by the default anti-spam policy."
  value       = data.msexchangeonline_hosted_content_filter_policy.default.spam_action
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `bulk_quarantine_tag` (String) Quarantine policy for bulk messages.
- `bulk_spam_action` (String) Action for bulk email at or above `bulk_threshold`. Valid values: `MoveToJmf`, `Quarantine`, `AddXHeader`.
- `bulk_threshold` (Number) Bulk complaint level threshold (1–9). Messages at or above this threshold trigger `bulk_spam_action`. Lower = stricter.
- `enabled` (Boolean) Whether the associated rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude messages sent to recipients in these domains.
- `except_if_sent_to` (List of String) Exclude messages sent to these specific recipients.
- `high_confidence_phish_action` (String) Action for high-confidence phishing messages. Valid values: `Quarantine`, `Delete`.
- `high_confidence_phish_quarantine_tag` (String) Quarantine policy for high-confidence phishing messages.
- `high_confidence_spam_action` (String) Action for high-confidence spam messages. Valid values: `MoveToJmf`, `Quarantine`, `Redirect`, `Delete`, `AddXHeader`.
- `high_confidence_spam_quarantine_tag` (String) Quarantine policy for high-confidence spam messages.
- `id` (String) The unique identifier of the spam filter policy.
- `increase_score_with_image_links` (String) Increase spam score for messages containing image links. Valid values: `On`, `Off`.
- `mark_as_spam_bulk_mail` (String) Mark bulk email as spam. Valid values: `On`, `Off`.
- `mark_as_spam_empty_messages` (String) Mark empty messages as spam. Valid values: `On`, `Off`.
- `phish_quarantine_tag` (String) Quarantine policy for phishing messages.
- `phish_spam_action` (String) Action for messages detected as phishing. Valid values: `MoveToJmf`, `Quarantine`, `Redirect`, `Delete`, `AddXHeader`.
- `priority` (Number) Priority of the associated rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority. Only applies when a recipient condition is set.
- `quarantine_tag` (String) Quarantine policy for spam messages. Leave empty to use the tenant default.
- `recipient_domain_is` (List of String) Apply this policy to messages sent to recipients in these domains.
- `sent_to` (List of String) Apply this policy to messages sent to these specific recipients.
- `sent_to_member_of` (List of String) Apply this policy to messages sent to members of these distribution groups.
- `spam_action` (String) Action for messages detected as spam. Valid values: `MoveToJmf`, `Quarantine`, `Redirect`, `Delete`, `AddXHeader`.
