# msexchangeonline_quarantine_global_settings (Data Source)

Reads the tenant-wide settings, with the attributes of the [`msexchangeonline_quarantine_global_settings`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/quarantine_global_settings) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_quarantine_global_settings" "this" {}

output "quarantine_notification_frequency" {
  description = "How often users receive quarantine notifications."
  value       = data.msexchangeonline_quarantine_global_settings.this.notification_frequency
}
```

## Schema

### Read-Only

- `id` (String) Always `default`.
- `languages` (Attributes Set) Customized notifications, at most three, one element per language. An empty set removes all of them. (see [below for nested schema](#nestedatt--languages))
- `notification_frequency` (String) How often users receive quarantine notifications. Valid values: `04:00:00` (4 hours), `1.00:00:00` (1 day), `7.00:00:00` (7 days).
- `organization_branding_enabled` (Boolean) Replace the Microsoft logo with the logo of the organization theme in the Microsoft 365 admin center.
- `sender_address` (String) Address of an existing internal sender used for quarantine notifications. Empty restores the Microsoft sender.

<a id="nestedatt--languages"></a>
### Nested Schema for `languages`

Read-Only:

- `disclaimer` (String) Text at the bottom of the notification, at most 200 characters.
- `language` (String) Language of the notification, for example `English`, `French` or `Default`, as in `Set-QuarantinePolicy -MultiLanguageSetting`.
- `sender_name` (String) Display name of the sender.
- `subject` (String) Subject of the notification.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
