# msexchangeonline_outbound_connector (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_outbound_connector`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/outbound_connector) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_outbound_connector" "on_premises" {
  name = "To On-Premises"
}

output "smart_hosts" {
  description = "The on-premises servers that receive mail through the connector."
  value       = data.msexchangeonline_outbound_connector.on_premises.smart_hosts
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `comment` (String) Optional description of the connector.
- `connector_source` (String) Read-only. How the connector was created. Values: `Default`, `HybridWizard`, `AdminUI`.
- `connector_type` (String) The type of the connector. Valid values: `OnPremises`, `Partner`.
- `enabled` (Boolean) Whether the connector is enabled.
- `id` (String) The unique identifier of the outbound connector.
- `recipient_domains` (List of String) Domain names to which this connector routes messages (e.g. `contoso.com`). Required for `Partner` connectors.
- `route_all_messages_via_on_premises` (Boolean) Route all outbound internet mail through on-premises hosts.
- `smart_hosts` (List of String) Smart host FQDNs or IP addresses used to route outbound mail (e.g. `mail.contoso.local`). Typically used for `OnPremises` connectors.
- `tls_settings` (String) TLS requirement for outbound connections. Valid values: `None`, `EncryptionOnly`, `CertificateVerification`, `DomainValidation`.
- `use_mx_record` (Boolean) Use MX records instead of smart hosts to route mail.

## Permissions

The provider's app registration needs the **Remote and Accepted Domains** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
