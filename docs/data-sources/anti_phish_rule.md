# msexchangeonline_anti_phish_rule (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_anti_phish_rule`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/anti_phish_rule) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_anti_phish_rule" "executives" {
  name = "Anti-Phish Rule - Executives"
}

output "enabled" {
  description = "Whether the anti-phishing rule for executives applies."
  value       = data.msexchangeonline_anti_phish_rule.executives.enabled
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `anti_phish_policy` (String) The name of the anti-phishing policy this rule applies. The policy must exist before the rule is created.
- `enabled` (Boolean) Whether the rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude messages sent to recipients in these domains.
- `except_if_sent_to` (List of String) Exclude messages sent to these specific recipients.
- `id` (String) The unique identifier of the anti-phishing rule.
- `priority` (Number) Priority of the rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority.
- `recipient_domain_is` (List of String) Apply this rule to messages sent to recipients in these domains.
- `sent_to` (List of String) Apply this rule to messages sent to these specific recipients (email addresses).
- `sent_to_member_of` (List of String) Apply this rule to messages sent to members of these distribution groups.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
