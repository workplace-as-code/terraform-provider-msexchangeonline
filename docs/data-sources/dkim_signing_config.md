# msexchangeonline_dkim_signing_config (Data Source)

Reads an existing object by `domain_name`, with the attributes of the [`msexchangeonline_dkim_signing_config`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/dkim_signing_config) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_dkim_signing_config" "contoso" {
  domain_name = "contoso.com"
}

output "selector1_cname" {
  description = "The first CNAME record to publish in the contoso.com DNS zone."
  value       = data.msexchangeonline_dkim_signing_config.contoso.selector1_cname
}
```

## Schema

### Required

- `domain_name` (String) Identifies the object to read.

### Read-Only

- `body_canonicalization` (String) Body canonicalization algorithm. Valid values: `Relaxed`, `Simple`.
- `enabled` (Boolean) Whether DKIM signing is enabled for the domain.
- `header_canonicalization` (String) Header canonicalization algorithm. Valid values: `Relaxed`, `Simple`.
- `id` (String) The unique identifier (same as `domain_name`).
- `key_size` (Number) DKIM key size in bits. Valid values: `1024`, `2048`. Reads as the key size of the selector in use after the last rotation, `0` when Exchange reports none. Only applies when the provider creates the configuration: Exchange cannot change the key size of an existing one, so a different value fails (rotate the key with `Rotate-DkimSigningConfig -KeySize`).
- `selector1_cname` (String) CNAME value to publish in DNS for selector 1 (read-only, set by Exchange Online).
- `selector2_cname` (String) CNAME value to publish in DNS for selector 2 (read-only, set by Exchange Online).

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
