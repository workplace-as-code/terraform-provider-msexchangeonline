# msexchangeonline_retention_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_retention_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/retention_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_retention_policy" "default" {
  name = "Default MRM Policy"
}

output "retention_policy_tag_links" {
  description = "The tags of the default retention policy."
  value       = data.msexchangeonline_retention_policy.default.retention_policy_tag_links
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `id` (String) The unique identifier of the retention policy.
- `is_default` (Boolean) Set this policy as the default retention policy applied to new mailboxes.
- `is_default_arbitration_mailbox` (Boolean) Whether this is the default retention policy for arbitration mailboxes (read-only).
- `retention_policy_tag_links` (Set of String) Names of the retention policy tags linked to this policy.

## Permissions

The provider's app registration needs the retention policy cmdlets of the **Retention Management** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only these cmdlets. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
