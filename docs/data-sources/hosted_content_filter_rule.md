# msexchangeonline_hosted_content_filter_rule (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_hosted_content_filter_rule`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/hosted_content_filter_rule) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_hosted_content_filter_rule" "strict" {
  name = "Strict Spam Filter Rule"
}

output "sent_to_member_of" {
  description = "The groups the strict spam filter rule applies to."
  value       = data.msexchangeonline_hosted_content_filter_rule.strict.sent_to_member_of
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `enabled` (Boolean) Whether the rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude recipients in these domains.
- `hosted_content_filter_policy` (String) Name of the hosted content filter policy this rule applies.
- `id` (String) The unique identifier of the spam filter rule.
- `priority` (Number) Priority of the rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority.
- `recipient_domain_is` (List of String) Apply this rule to recipients in these domains.
- `sent_to_member_of` (List of String) Apply this rule to members of these groups.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
