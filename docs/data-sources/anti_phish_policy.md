# msexchangeonline_anti_phish_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_anti_phish_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/anti_phish_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_anti_phish_policy" "default" {
  name = "Office365 AntiPhish Default"
}

output "enable_spoof_intelligence" {
  description = "Whether spoof intelligence is on in the default anti-phishing policy."
  value       = data.msexchangeonline_anti_phish_policy.default.enable_spoof_intelligence
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `authentication_fail_action` (String) Action for messages that fail authentication checks. Valid values: `MoveToJmf`, `Redirect`, `Quarantine`, `Delete`, `BccMessage`.
- `enable_first_contact_safety_tips` (Boolean) Show a safety tip when a user receives an email from a sender they haven't contacted before.
- `enable_mailbox_intelligence` (Boolean) Enable mailbox intelligence to improve impersonation detection based on user email patterns. Needs Microsoft Defender for Office 365.
- `enable_mailbox_intelligence_protection` (Boolean) Enable mailbox intelligence protection actions. Requires `enable_mailbox_intelligence = true`. Needs Microsoft Defender for Office 365.
- `enable_organization_domains_protection` (Boolean) Protect the organization's own domains from impersonation attacks. Needs Microsoft Defender for Office 365.
- `enable_spoof_intelligence` (Boolean) Enable spoof intelligence to detect and block spoofed senders.
- `enable_unauthenticated_sender` (Boolean) Show a `?` symbol in Outlook when the sender cannot be authenticated.
- `enable_via_tag` (Boolean) Show a `via` tag in Outlook when the sender address differs from the DKIM signature or MAIL FROM address.
- `enabled` (Boolean) Whether the associated rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude messages sent to recipients in these domains.
- `id` (String) The unique identifier of the anti-phishing policy.
- `mailbox_intelligence_protection_action` (String) Action for messages detected via mailbox intelligence. Valid values: `NoAction`, `MoveToJmf`, `Redirect`, `Quarantine`, `Delete`, `BccMessage`. Needs Microsoft Defender for Office 365.
- `phish_threshold_level` (Number) Aggressiveness of phishing detection. `1` = Standard, `2` = Aggressive, `3` = More aggressive, `4` = Most aggressive. Needs Microsoft Defender for Office 365.
- `priority` (Number) Priority of the associated rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority. Only applies when a recipient condition is set.
- `recipient_domain_is` (List of String) Apply this policy to messages sent to recipients in these domains.
- `sent_to_member_of` (List of String) Apply this policy to messages sent to members of these distribution groups.
