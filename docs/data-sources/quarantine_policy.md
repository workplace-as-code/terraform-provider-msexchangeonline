# msexchangeonline_quarantine_policy (Data Source)

Reads an existing object by name, with the attributes of the [`msexchangeonline_quarantine_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/quarantine_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_quarantine_policy" "full_access" {
  name = "DefaultFullAccessPolicy"
}

output "full_access_permissions" {
  description = "What users may do with their quarantined messages under the built-in policy."
  value       = data.msexchangeonline_quarantine_policy.full_access.end_user_quarantine_permissions_value
}
```

## Schema

### Required

- `name` (String) Name of the quarantine policy.

### Read-Only

- `end_user_quarantine_permissions_value` (Number) Bitmask integer defining end-user permissions. See Microsoft docs for values (e.g. `17` = view + release request).
- `esn_enabled` (Boolean) Enable end-user spam notifications for this quarantine policy.
- `id` (String) The unique identifier of the quarantine policy.
- `quarantine_retention_days` (Number) Number of days messages are held in quarantine (1–30).

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
