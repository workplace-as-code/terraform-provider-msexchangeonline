# msexchangeonline_offline_address_book (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_offline_address_book`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/offline_address_book) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_offline_address_book" "default" {
  name = "Default Offline Address Book"
}

output "default_address_lists" {
  description = "Address lists of the default offline address book."
  value       = data.msexchangeonline_offline_address_book.default.address_lists
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `address_lists` (Set of String) Names of the address lists in the offline address book, usually the GAL of an address book policy. Required to create it.
- `id` (String) The object name (same as `name`).

## Permissions

The provider's app registration needs the offline address book cmdlets of the **Address Lists** Exchange management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes. Exchange Online does not give this role to Organization Management by default. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
