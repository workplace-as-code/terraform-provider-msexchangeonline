# msexchangeonline_report_submission_policy (Data Source)

Reads the tenant-wide settings, with the attributes of the [`msexchangeonline_report_submission_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/report_submission_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_report_submission_policy" "this" {}

output "reporting_mailbox" {
  description = "Mailbox that receives user reported messages."
  value       = data.msexchangeonline_report_submission_policy.this.reporting_mailbox
}
```

## Schema

### Read-Only

- `disable_quarantine_reporting_option` (Boolean) Prevent users from reporting messages in quarantine.
- `enable_custom_notification_sender` (Boolean) Use `notification_sender_address` for result messages.
- `enable_organization_branding` (Boolean) Show the company logo in the footer of result messages.
- `enable_report_to_microsoft` (Boolean) Send reported messages to Microsoft. `false` with no reporting mailbox turns reporting in Outlook off.
- `enable_third_party_address` (Boolean) Users report with a non-Microsoft tool. Requires `reporting_mailbox` and `enable_report_to_microsoft = false`.
- `enable_user_email_notification` (Boolean) Send users a result message after an admin reviews what they reported.
- `id` (String) Always `default`.
- `junk_review_result_message` (String) Text of the result message for junk.
- `languages` (Attributes Set) Customized messages, one element per language. Exchange Online cannot remove the last language: the set needs at least one element. (see [below for nested schema](#nestedatt--languages))
- `not_junk_review_result_message` (String) Text of the result message for not junk.
- `notification_footer_message` (String) Footer of result messages.
- `notification_sender_address` (String) Sender of result messages. Empty removes it.
- `phishing_review_result_message` (String) Text of the result message for phishing.
- `post_submit_message` (String) Text of the message shown after users report.
- `post_submit_message_enabled` (Boolean) Show a message after users report.
- `post_submit_message_title` (String) Title of the message shown after users report.
- `pre_submit_message` (String) Text of the message shown before users report.
- `pre_submit_message_enabled` (Boolean) Show a message before users report.
- `pre_submit_message_title` (String) Title of the message shown before users report.
- `reporting_mailbox` (String) Exchange Online mailbox that receives user reported messages, written to the policy and to the rule. Empty sends nothing to a mailbox and removes the rule. The mailbox must already exist.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it.
