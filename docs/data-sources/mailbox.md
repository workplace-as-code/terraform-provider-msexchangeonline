# msexchangeonline_mailbox (Data Source)

Reads an Exchange Online mailbox. Mailboxes are read-only from this provider — use this data source to reference mailbox properties in other resources.

## Example Usage

```terraform
data "msexchangeonline_mailbox" "helpdesk" {
  identity = "helpdesk@contoso.com"
}

output "helpdesk_address" {
  description = "Primary SMTP address of the helpdesk mailbox."
  value       = data.msexchangeonline_mailbox.helpdesk.primary_smtp_address
}
```

## Schema

### Required

- `identity` (String) The mailbox identity to look up. Accepts UPN, email address, alias, or display name.

### Read-Only

- `display_name` (String) The display name of the mailbox.
- `email_addresses` (List of String) All SMTP proxy addresses associated with the mailbox.
- `hidden_from_address_lists_enabled` (Boolean) Whether the mailbox is hidden from the Global Address List.
- `id` (String) The Exchange identity of the mailbox (same as `identity`).
- `litigation_hold_enabled` (Boolean) Whether litigation hold is enabled on the mailbox.
- `primary_smtp_address` (String) The primary SMTP address of the mailbox.
- `recipient_type_details` (String) The mailbox type: `UserMailbox`, `SharedMailbox`, `RoomMailbox`, `EquipmentMailbox`, etc.
- `retention_policy` (String) The retention policy applied to the mailbox. Empty string if none.

## Permissions

The provider's app registration needs the **Mail Recipient Creation** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
