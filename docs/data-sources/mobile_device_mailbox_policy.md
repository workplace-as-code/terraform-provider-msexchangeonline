# msexchangeonline_mobile_device_mailbox_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_mobile_device_mailbox_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/mobile_device_mailbox_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_mobile_device_mailbox_policy" "default" {
  name = "Default"
}

output "min_password_length" {
  description = "The minimum device password length in the default policy."
  value       = data.msexchangeonline_mobile_device_mailbox_policy.default.min_password_length
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `allow_bluetooth` (String) Bluetooth setting. Valid values: `Allow`, `Disable`, `HandsfreeOnly`.
- `allow_browser` (Boolean) Allow the built-in web browser.
- `allow_camera` (Boolean) Allow the device camera.
- `allow_simple_password` (Boolean) Allow simple numeric passwords.
- `allow_storage_card` (Boolean) Allow removable storage cards.
- `allow_text_messaging` (Boolean) Allow SMS / text messaging.
- `allow_wifi` (Boolean) Allow Wi-Fi connections.
- `alphanumeric_password_required` (Boolean) Require an alphanumeric password.
- `device_encryption_enabled` (Boolean) Require device encryption.
- `id` (String) The unique identifier of the mobile device mailbox policy.
- `is_default` (Boolean) Set this policy as the default mobile device mailbox policy.
- `max_inactivity_time_lock` (String) Screen lock timeout as a timespan string (e.g. `00:05:00` for 5 minutes).
- `max_password_failed_attempts` (Number) Failed password attempts before the device is wiped, from 4 to 16. `0` means unlimited.
- `min_password_length` (Number) Minimum password length.
- `password_enabled` (Boolean) Require a password on the device.
- `password_recovery_enabled` (Boolean) Enable password recovery.
- `require_device_encryption` (Boolean) Enforce storage card encryption.

## Permissions

The provider's app registration needs the **Recipient Policies** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
