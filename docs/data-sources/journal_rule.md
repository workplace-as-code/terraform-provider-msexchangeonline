# msexchangeonline_journal_rule (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_journal_rule`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/journal_rule) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_journal_rule" "archive" {
  name = "Archive all mail"
}

output "journal_email_address" {
  description = "The address that receives the journal reports."
  value       = data.msexchangeonline_journal_rule.archive.journal_email_address
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `enabled` (Boolean) Whether the rule is enabled.
- `id` (String) The object name (same as `name`).
- `journal_email_address` (String) Address that receives the journal reports: an archiving system or service outside Exchange Online, never an Exchange Online mailbox.
- `recipient` (String) SMTP address of the mailbox, contact or group whose messages are journaled. `""` journals the messages of every recipient.
- `scope` (String) Messages the rule journals: all of them, internal ones or external ones. Valid values: `Global`, `Internal`, `External` (case-insensitive).

## Permissions

The provider's app registration needs the **Journaling** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
