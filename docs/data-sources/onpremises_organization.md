# msexchangeonline_onpremises_organization (Data Source)

Reads the on-premises organization that the Hybrid Configuration Wizard creates in Exchange Online (`Get-OnPremisesOrganization`), by `name`. Read only: the Hybrid Configuration Wizard manages it.

## Example Usage

```terraform
data "msexchangeonline_onpremises_organization" "hybrid" {
  name = "Contoso Hybrid"
}

output "hybrid_domains" {
  value = data.msexchangeonline_onpremises_organization.hybrid.hybrid_domains
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `comment` (String) Comment written by the wizard.
- `hybrid_domains` (Set of String) Domains shared by the two organizations.
- `id` (String) The object name (same as `name`).
- `inbound_connector` (String) Inbound connector of the hybrid mail flow.
- `organization_guid` (String) GUID of the on-premises Exchange organization.
- `organization_name` (String) Name of the on-premises Exchange organization.
- `organization_relationship` (String) Organization relationship with the on-premises organization.
- `outbound_connector` (String) Outbound connector of the hybrid mail flow.

## Permissions

The provider's app registration needs the `Get-OnPremisesOrganization` cmdlet, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
