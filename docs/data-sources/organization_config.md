# msexchangeonline_organization_config (Data Source)

Reads the Exchange Online organization configuration. Use this data source to reference tenant-level settings in other resources.

## Example Usage

```terraform
data "msexchangeonline_organization_config" "tenant" {}

output "max_send_size" {
  description = "Largest message, in bytes, that users of the tenant can send."
  value       = data.msexchangeonline_organization_config.tenant.max_send_size
}
```

## Schema

### Read-Only

- `audit_disabled` (Boolean) Whether mailbox audit logging is disabled at the organization level.
- `display_name` (String) The display name of the organization.
- `focused_inbox_on` (Boolean) Whether Focused Inbox is enabled for the organization.
- `id` (String) The Exchange identity of the organization configuration object.
- `max_receive_size` (Number) Maximum message receive size in bytes. `-1` means unlimited.
- `max_send_size` (Number) Maximum message send size in bytes. `-1` means unlimited.
- `outbound_spam_filtering_enabled` (Boolean) Whether outbound spam filtering is enabled.
- `read_tracking_enabled` (Boolean) Whether read receipt tracking is enabled for the organization.
- `scl_junk_threshold` (Number) The spam confidence level (SCL) threshold above which messages are moved to the Junk Email folder.

## Permissions

The provider's app registration needs the **Organization Configuration** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
