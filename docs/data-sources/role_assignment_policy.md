# msexchangeonline_role_assignment_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_role_assignment_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/role_assignment_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_role_assignment_policy" "default" {
  name = "Default Role Assignment Policy"
}

output "default_end_user_roles" {
  description = "What users can change on their own mailbox by default."
  value       = data.msexchangeonline_role_assignment_policy.default.roles
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `description` (String) Description of the policy.
- `id` (String) The policy name.
- `is_default` (Boolean) Whether new mailboxes get this policy. Making a policy the default removes the flag from the previous default policy.
- `roles` (Set of String) End-user roles of the policy, for example `MyBaseOptions`, `MyContactInformation`, `MyDistributionGroupMembership`. A role left out is removed from the policy.

## Permissions

The provider's app registration needs the **Role Management** Exchange management role (`tools/new_role_group.ps1` grants it with `-IncludeRoleManagement`). See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
