# msexchangeonline_cross_tenant_partner (Data Source)

Reads an existing object by `partner_tenant_id`, with the attributes of the [`msexchangeonline_cross_tenant_partner`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/cross_tenant_partner) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_cross_tenant_partner" "fabrikam" {
  partner_tenant_id = "00000000-0000-0000-0000-000000000000"
}

output "fabrikam_capabilities" {
  description = "The Exchange capabilities opened to Fabrikam."
  value       = [for c in data.msexchangeonline_cross_tenant_partner.fabrikam.capabilities : c.name]
}
```

- `id` (String) The partner tenant ID, in lowercase.

### Nested Schema for `capabilities`

Read-Only:

- `allowed` (Boolean) Whether the partner's users can use the capability.
- `excluded_groups` (Set of String) Object IDs of the groups whose members the capability never applies to.
- `excluded_users` (Set of String) Object IDs of the users the capability never applies to.
- `included_groups` (Set of String) Object IDs of the groups whose members the capability applies to. Without any included group or user, it applies to all users.
- `included_users` (Set of String) Object IDs of the users the capability applies to.
- `name` (String) The capability. Valid values: `crossTenantCalendarAvailabilityBasic`, `crossTenantCalendarAvailabilityLimitedDetails`, `crossTenantMailTipsAll`, `crossTenantMailTipsLimited`, `crossTenantCalendarSharingFreeBusySimple`, `crossTenantCalendarSharingFreeBusyDetail`, `crossTenantCalendarSharingFreeBusyReviewer`.

## Permissions

The app registration needs the Microsoft Graph application permission `Policy.ReadWrite.CrossTenantCapability` and the Microsoft Entra role **Exchange Administrator** (or Global Administrator): Microsoft Graph refuses these capabilities to an app without one of these roles, also to read them. The list resource (`terraform query`) also needs `Policy.Read.All`. No Exchange management role is involved. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
