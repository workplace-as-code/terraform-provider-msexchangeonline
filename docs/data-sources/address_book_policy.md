# msexchangeonline_address_book_policy (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_address_book_policy`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/address_book_policy) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_address_book_policy" "contoso" {
  name = "Contoso"
}

output "contoso_global_address_list" {
  description = "GAL of the Contoso address book policy."
  value       = data.msexchangeonline_address_book_policy.contoso.global_address_list
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `address_lists` (Set of String) Names of the address lists users see besides the GAL.
- `global_address_list` (String) Name of the global address list.
- `id` (String) The object name (same as `name`).
- `offline_address_book` (String) Name of the offline address book.
- `room_list` (String) Name of the address list of the rooms users can book, an address list whose filter selects room mailboxes.

## Permissions

The provider's app registration needs the address book policy cmdlets of the **Address Lists** Exchange management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes. Exchange Online does not give this role to Organization Management by default. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
