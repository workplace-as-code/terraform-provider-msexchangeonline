# msexchangeonline_intra_organization_connector (Data Source)

Reads an intra-organization connector, which the Hybrid Configuration Wizard creates for the free/busy and MailTips of hybrid modern authentication (`Get-IntraOrganizationConnector`), by `name`. Read only: the Hybrid Configuration Wizard manages it.

## Example Usage

```terraform
data "msexchangeonline_intra_organization_connector" "hybrid" {
  name = "HybridIOC - 00000000-0000-0000-0000-000000000000"
}

output "hybrid_discovery_endpoint" {
  value = data.msexchangeonline_intra_organization_connector.hybrid.discovery_endpoint
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `discovery_endpoint` (String) Autodiscover endpoint of the on-premises organization.
- `enabled` (Boolean) Whether the connector is used.
- `id` (String) The object name (same as `name`).
- `target_address_domains` (Set of String) Domains of the on-premises organization.
- `target_sharing_epr` (String) Exchange Web Services endpoint of the on-premises organization, when Autodiscover cannot find it.

## Permissions

The provider's app registration needs the `Get-IntraOrganizationConnector` cmdlet, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
