# msexchangeonline_atp_protection_policy_rule (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_atp_protection_policy_rule`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/atp_protection_policy_rule) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_atp_protection_policy_rule" "standard" {
  name = "Standard Preset Security Policy"
}

output "enabled" {
  description = "Whether the Defender part of the Standard preset is on."
  value       = data.msexchangeonline_atp_protection_policy_rule.standard.enabled
}
```

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `comments` (String) Comments about the rule.
- `enabled` (Boolean) Whether the preset security policy applies. Turning it off keeps the rule and its recipients.
- `except_if_recipient_domain_is` (List of String) Exception: the recipient's domain is one of these accepted domains.
- `except_if_sent_to` (List of String) Exception: the recipient is one of these mailboxes, mail users or contacts.
- `except_if_sent_to_member_of` (List of String) Exception: the recipient is a member of one of these groups.
- `id` (String) The object name (same as `name`).
- `recipient_domain_is` (List of String) Condition: the recipient's domain is one of these accepted domains.
- `sent_to` (List of String) Condition: the recipient is one of these mailboxes, mail users or contacts.
- `sent_to_member_of` (List of String) Condition: the recipient is a member of one of these groups.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it.
