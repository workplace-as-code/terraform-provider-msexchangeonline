# msexchangeonline_management_role (Data Source)

Reads an Exchange management role, built-in or custom, and the cmdlets it contains (`Get-ManagementRole`, `Get-ManagementRoleEntry`).

## Example Usage

```terraform
data "msexchangeonline_management_role" "transport_rules" {
  name = "Transport Rules"
}

output "transport_rules_cmdlets" {
  description = "Cmdlets of the built-in Transport Rules role."
  value       = data.msexchangeonline_management_role.transport_rules.cmdlets
}
```

## Schema

### Required

- `name` (String) The name of the role to read.

### Read-Only

- `built_in` (Boolean) Whether Microsoft provides the role.
- `cmdlets` (Set of String) The cmdlets the role contains.
- `description` (String) The description of the role.
- `id` (String) The name of the role.
- `parent` (String) The role this role derives from. Empty for a built-in root role.

## Permissions

The provider's app registration needs a management role that grants `Get-ManagementRole` and `Get-ManagementRoleEntry`, such as the read-only **View-Only Configuration**. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
