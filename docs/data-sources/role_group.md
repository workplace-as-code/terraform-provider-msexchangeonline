# msexchangeonline_role_group (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_role_group`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/role_group) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_role_group" "organization_management" {
  name = "Organization Management"
}

output "organization_management_description" {
  value = data.msexchangeonline_role_group.organization_management.description
}
```

### Read-Only

- `description` (String) Description of the role group.
- `display_name` (String) Name shown in the Exchange admin center. Defaults to `name`.
- `id` (String) The object name (same as `name`).
- `managed_by` (Set of String) Users or groups that can change the members of the role group.

## Permissions

The provider's app registration needs the **Role Management** Exchange management role (`tools/new_role_group.ps1` grants it with `-IncludeRoleManagement`). See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
