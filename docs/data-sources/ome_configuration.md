# msexchangeonline_ome_configuration (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_ome_configuration`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/ome_configuration) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_ome_configuration" "default" {
  name = "OME Configuration"
}

output "otp_enabled" {
  description = "Whether recipients can open the portal with a one-time passcode."
  value       = data.msexchangeonline_ome_configuration.default.otp_enabled
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `background_color` (String) Background color, as an HTML name or a hex code such as `#ffffff`.
- `disclaimer_text` (String) Disclaimer at the bottom of the message.
- `email_text` (String) Text of the message the recipient receives.
- `external_mail_expiry_in_days` (Number) Days external recipients can read the message in the portal, from 1 to 730; `0` for no expiry. Custom templates only.
- `id` (String) The object name (same as `name`).
- `image` (String) Logo, as base64 (`filebase64("logo.png")`): PNG, JPG, BMP or TIFF, ideally under 40 KB and 170 x 70 pixels. `""` removes the logo. Exchange re-encodes the image: the configured value is kept as long as Exchange returns the image it stored at the last write.
- `introduction_text` (String) Text after the sender's name and address.
- `otp_enabled` (Boolean) Let recipients sign in to the portal with a one-time passcode.
- `portal_text` (String) Text at the top of the encrypted message portal.
- `privacy_statement_url` (String) Address of the privacy statement link.
- `read_button_text` (String) Text of the Read the message button.
- `social_id_sign_in` (Boolean) Let recipients sign in with a Microsoft, Google or Yahoo account.
