# msexchangeonline_tenant_allow_block_list_spoof_item (Data Source)

Reads an existing object by `id`, with the attributes of the [`msexchangeonline_tenant_allow_block_list_spoof_item`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/tenant_allow_block_list_spoof_item) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_tenant_allow_block_list_spoof_item" "partner" {
  id = "External:contoso.com:mail.fabrikam.com"
}

output "partner_spoof_action" {
  description = "Whether the partner is allowed or blocked."
  value       = data.msexchangeonline_tenant_allow_block_list_spoof_item.partner.action
}
```

## Schema

### Required

- `id` (String) Identifies the object to read.

### Read-Only

- `action` (String) `Allow` or `Block`.
- `sending_infrastructure` (String) Source of the messages: a domain found in the reverse DNS of the sending server, a verified DKIM domain, or an IP address written `<address>/24`. Changing it creates a new entry.
- `spoof_type` (String) `Internal` or `External`. Changing it creates a new entry.
- `spoofed_user` (String) Email address for a sender inside the organization, domain for a sender outside it. Changing it creates a new entry.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it.
