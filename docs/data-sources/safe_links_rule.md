# msexchangeonline_safe_links_rule (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_safe_links_rule`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/safe_links_rule) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_safe_links_rule" "all_users" {
  name = "Safe Links Rule - All Users"
}

output "enabled" {
  description = "Whether the Safe Links rule for all users applies."
  value       = data.msexchangeonline_safe_links_rule.all_users.enabled
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `enabled` (Boolean) Whether the rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude recipients in these domains.
- `id` (String) The unique identifier of the Safe Links rule.
- `priority` (Number) Priority of the rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority.
- `recipient_domain_is` (List of String) Apply this rule to recipients in these domains.
- `safe_links_policy` (String) Name of the Safe Links policy this rule applies.
- `sent_to_member_of` (List of String) Apply this rule to members of these distribution groups.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. The tenant needs a Microsoft Defender for Office 365 (Plan 1 or 2) license. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
