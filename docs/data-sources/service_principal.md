# msexchangeonline_service_principal (Data Source)

Reads an existing object by `app_id`, with the attributes of the [`msexchangeonline_service_principal`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/service_principal) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_service_principal" "mail_sender" {
  app_id = "00000000-0000-0000-0000-000000000000"
}

output "mail_sender_display_name" {
  value = data.msexchangeonline_service_principal.mail_sender.display_name
}
```

## Schema

### Required

- `app_id` (String) Identifies the object to read.

### Read-Only

- `display_name` (String) Name shown in Exchange Online.
- `id` (String) The app ID.
- `object_id` (String) Object ID of the app's enterprise application (service principal) in Microsoft Entra, not the object ID of the app registration. Changing it creates a new service principal.

## Permissions

The provider's app registration needs the **Role Management** Exchange management role (`tools/new_role_group.ps1` grants it with `-IncludeRoleManagement`). See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
