# msexchangeonline_inbound_connector (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_inbound_connector`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/inbound_connector) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_inbound_connector" "on_premises" {
  name = "From On-Premises"
}

output "sender_ip_addresses" {
  description = "The on-premises IP addresses the connector accepts mail from."
  value       = data.msexchangeonline_inbound_connector.on_premises.sender_ip_addresses
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `comment` (String) Optional description of the connector.
- `connector_source` (String) Read-only. How the connector was created. Values: `Default`, `HybridWizard`, `AdminUI`.
- `connector_type` (String) The type of the connector. Valid values: `OnPremises`, `Partner`.
- `enabled` (Boolean) Whether the connector is enabled.
- `id` (String) The unique identifier of the inbound connector.
- `require_tls` (Boolean) Require TLS for inbound connections.
- `restrict_domains_to_certificate` (Boolean) Verify that the TLS certificate used by the sender matches `tls_sender_certificate_name`.
- `sender_domains` (List of String) Domain names from which this connector accepts messages (e.g. `contoso.com`). Required for `Partner` connectors.
- `sender_ip_addresses` (List of String) IP addresses or ranges from which this connector accepts messages (e.g. `203.0.113.0/24`). Typically used for `OnPremises` connectors.
- `tls_sender_certificate_name` (String) The certificate subject expected from the sending server when `restrict_domains_to_certificate = true`.

## Permissions

The provider's app registration needs the **Remote and Accepted Domains** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
