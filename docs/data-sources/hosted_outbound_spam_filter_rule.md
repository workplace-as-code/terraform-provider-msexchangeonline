# msexchangeonline_hosted_outbound_spam_filter_rule (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_hosted_outbound_spam_filter_rule`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/hosted_outbound_spam_filter_rule) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_hosted_outbound_spam_filter_rule" "bulk_senders" {
  name = "Bulk senders"
}

output "from_member_of" {
  description = "The groups the outbound spam rule applies to."
  value       = data.msexchangeonline_hosted_outbound_spam_filter_rule.bulk_senders.from_member_of
}
```

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it.
