# msexchangeonline_management_scope (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_management_scope`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/management_scope) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_management_scope" "france" {
  name = "France"
}

output "france_filter" {
  value = data.msexchangeonline_management_scope.france.recipient_restriction_filter
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `exclusive` (Boolean) An exclusive scope: only the assignments that use it can change its recipients, even for administrators with organization-wide roles. Changing it creates a new scope.
- `id` (String) The object name (same as `name`).
- `recipient_restriction_filter` (String) OPATH filter of the recipients in the scope, for example `CustomAttribute1 -eq 'France'`. Exchange rewrites it with parentheses: the configured text is kept as long as Exchange returns the text it wrote.
- `recipient_root` (String) Organizational unit the filter applies to. Empty for the whole organization.

## Permissions

The provider's app registration needs the **Role Management** Exchange management role (`tools/new_role_group.ps1` grants it with `-IncludeRoleManagement`). See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
