# msexchangeonline_remote_domain (Data Source)

Reads an existing object by `name`, with the attributes of the [`msexchangeonline_remote_domain`](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/resources/remote_domain) resource. Use it to reference an object that this configuration does not manage, such as a default policy.

## Example Usage

```terraform
data "msexchangeonline_remote_domain" "default" {
  name = "Default"
}

output "auto_forward_enabled" {
  description = "Whether mail can be forwarded automatically to external domains."
  value       = data.msexchangeonline_remote_domain.default.auto_forward_enabled
}
```

## Schema

### Required

- `name` (String) Identifies the object to read.

### Read-Only

- `allowed_oof_type` (String) Type of out-of-office messages allowed. Valid values: `External`, `ExternalLegacy`, `InternalLegacy`, `None`.
- `auto_forward_enabled` (Boolean) Allow auto-forwarding of messages to recipients in this domain.
- `auto_reply_enabled` (Boolean) Allow automatic replies to recipients in this domain.
- `domain_name` (String) The SMTP domain (e.g. `partner-bank.com`). Immutable after creation.
- `id` (String) The unique identifier of the remote domain (same as `name`).
- `tnef_enabled` (String) TNEF (Winmail.dat) encoding. `"true"` to force, `"false"` to disable, `""` to inherit the organization default.
- `trusted_mail_inbound_enabled` (Boolean) Trust inbound mail from this domain (bypass some spam filters).
- `trusted_mail_outbound_enabled` (Boolean) Trust outbound mail to this domain.

## Permissions

The provider's app registration needs the **Remote and Accepted Domains** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
