# msexchangeonline_irm_configuration (Resource)

Manages the Information Rights Management (IRM) configuration of the organization: Microsoft Purview Message Encryption, and how Exchange decrypts protected messages (`Set-IRMConfiguration`). This is a singleton: there is exactly one per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. It needs Microsoft Purview Message Encryption (Microsoft 365 E3 or E5, Office 365 E3 or E5, or Azure Information Protection Plan 1). Legacy AD RMS settings are not managed.

## Example Usage

```terraform
# Purview Message Encryption on, with the Encrypt-Only and Do Not Forward
# options in Outlook on the web
resource "msexchangeonline_irm_configuration" "this" {
  azure_rms_licensing_enabled       = true
  internal_licensing_enabled        = true
  simplified_client_access_enabled  = true
  transport_decryption_setting      = "Optional"
  journal_report_decryption_enabled = true
  enable_portal_tracking_logs       = true
}
```

## Schema

### Optional

- `automatic_service_update_enabled` (Boolean) Let Microsoft add new Azure Information Protection features automatically.
- `azure_rms_licensing_enabled` (Boolean) Connect to Azure Rights Management: turns Microsoft Purview Message Encryption on.
- `decrypt_attachment_for_encrypt_only` (Boolean) Give recipients unrestricted rights on the attachments of Encrypt-Only messages.
- `ediscovery_super_user_enabled` (Boolean) Let eDiscovery searches read protected messages.
- `enable_pdf_encryption` (Boolean) Encrypt PDF attachments of encrypted messages.
- `enable_portal_tracking_logs` (Boolean) Log the activity of the encrypted message portal (Advanced Message Encryption).
- `internal_licensing_enabled` (Boolean) Use IRM for messages sent inside the organization.
- `journal_report_decryption_enabled` (Boolean) Add a decrypted copy of protected messages to journal reports.
- `reject_if_recipient_has_no_rights` (Boolean) Reject a protected message sent to a recipient who has no rights on it.
- `search_enabled` (Boolean) Let users search encrypted messages in Outlook on the web.
- `simplified_client_access_do_not_forward_disabled` (Boolean) Hide the Do Not Forward option in Outlook on the web.
- `simplified_client_access_enabled` (Boolean) Show the Protect button in Outlook on the web.
- `simplified_client_access_encrypt_only_disabled` (Boolean) Hide the Encrypt-Only option in Outlook on the web.
- `transport_decryption_setting` (String) Whether Exchange decrypts protected messages in transport, for example to scan them. Valid values: `Disabled`, `Optional`, `Mandatory` (case-insensitive).

### Read-Only

- `id` (String) Always `default`.

## Destroy

Destroying the resource only removes it from the Terraform state: the settings stay as they are, so that
removing the code never turns message encryption off.

## Permissions

The provider's app registration needs the **Information Rights Management** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

The resource is a singleton. Import it with the ID `default`:

```terraform
import {
  to = msexchangeonline_irm_configuration.this
  id = "default"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_irm_configuration.this
  identity = { id = "default" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_irm_configuration.this "default"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
