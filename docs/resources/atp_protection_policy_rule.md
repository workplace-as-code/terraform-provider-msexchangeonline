# msexchangeonline_atp_protection_policy_rule (Resource)

Manages the Defender for Office 365 part of a preset security policy (Standard or Strict): whether Safe Links and Safe Attachments protection applies, and to which recipients. Needs Defender for Office 365 (`New-ATPProtectionPolicyRule`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `name` is `Standard Preset Security Policy` or `Strict Preset Security Policy`. The rule is not created: it exists once the Defender for Office 365 part of the preset has been applied to recipients in the Microsoft Defender portal, and the resource adopts it. Destroying the resource turns the preset off and keeps the rule. A condition left out of the configuration is not managed: set it to `[]` to clear it.

## Example Usage

```terraform
# Safe Links and Safe Attachments of the Standard preset for the same group.
resource "msexchangeonline_atp_protection_policy_rule" "standard" {
  name              = "Standard Preset Security Policy"
  enabled           = true
  sent_to_member_of = ["Standard protection pilot"]
}
```

### Optional

- `except_if_recipient_domain_is` (List of String) Exception: the recipient's domain is one of these accepted domains.
- `except_if_sent_to` (List of String) Exception: the recipient is one of these mailboxes, mail users or contacts.
- `except_if_sent_to_member_of` (List of String) Exception: the recipient is a member of one of these groups.
- `recipient_domain_is` (List of String) Condition: the recipient's domain is one of these accepted domains.
- `sent_to` (List of String) Condition: the recipient is one of these mailboxes, mail users or contacts.
- `sent_to_member_of` (List of String) Condition: the recipient is a member of one of these groups.

### Read-Only

- `id` (String) The object name (same as `name`).
