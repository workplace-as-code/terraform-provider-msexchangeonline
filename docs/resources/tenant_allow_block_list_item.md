# msexchangeonline_tenant_allow_block_list_item (Resource)

Manages an entry of the Tenant Allow/Block List (`New-TenantAllowBlockListItems`): a sender, URL, file hash or IP address that Exchange Online Protection always blocks or allows. Exchange Online only.

## Example Usage

```terraform
# Block a spoofing domain and a phishing URL.
resource "msexchangeonline_tenant_allow_block_list_item" "spoofed_domain" {
  list_type = "Sender"
  entry     = "contoso-billing.example"
  action    = "Block"
  notes     = "Lookalike domain used in invoice fraud"
}

resource "msexchangeonline_tenant_allow_block_list_item" "phishing_url" {
  list_type       = "Url"
  entry           = "login.contoso-billing.example/*"
  action          = "Block"
  expiration_date = "2027-01-01T00:00:00Z"
}
```

## Schema

### Required

- `action` (String) `Block` or `Allow`. Changing it creates a new entry.
- `entry` (String) The sender, URL, file hash or IP address. Changing it creates a new entry.
- `list_type` (String) List the entry belongs to. Valid values: `Sender` (email address or domain), `Url`, `FileHash` (SHA256), `IP` (IPv6 address or range).

### Optional

- `expiration_date` (String) Date the entry expires, in RFC 3339 format and UTC, for example `2027-01-31T00:00:00Z`. When omitted at creation, a `Block` entry never expires (empty value) and an `Allow` entry is removed 45 days after it was last used.
- `notes` (String) Free text describing the entry.

### Read-Only

- `id` (String) `<list_type>:<entry>`.
