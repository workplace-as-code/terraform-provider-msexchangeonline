# msexchangeonline_accepted_domain (Resource)

Manages the settings of an accepted domain. Exchange Online cannot create or remove accepted domains: a domain added and verified in the Microsoft 365 admin center becomes one. Creating this resource adopts the existing domain (`name` must match its current name), and destroying it only removes it from Terraform state.

## Example Usage

```terraform
resource "msexchangeonline_accepted_domain" "contoso_com" {
  name        = "Contoso"
  domain_name = "contoso.com"
  domain_type = "Authoritative"
}

resource "msexchangeonline_accepted_domain" "subsidiary_relay" {
  name        = "Subsidiary Internal Relay"
  domain_name = "subsidiary.contoso.com"
  domain_type = "InternalRelay"
}
```

## Schema

### Required

- `domain_name` (String) The SMTP domain (e.g. `contoso.com`). In Exchange Online, the domain must already be added to the Microsoft 365 tenant and verified with a DNS record.
- `name` (String) Friendly name for the accepted domain entry.

### Optional

- `domain_type` (String) Type of accepted domain: `Authoritative`, or `InternalRelay` when some recipients of the domain are hosted on another email system.
- `match_sub_domains` (Boolean) Route mail for all subdomains of this domain through Exchange Online.

### Read-Only

- `default` (Boolean) Whether this is the default accepted domain (read-only).
- `id` (String) The unique identifier of the accepted domain.

## Permissions

## Import

Import using the domain identity (same as `name`):

```terraform
import {
  to = msexchangeonline_accepted_domain.example
  id = "Contoso"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_accepted_domain.example
  identity = { id = "Contoso" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_accepted_domain.example "Contoso"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
