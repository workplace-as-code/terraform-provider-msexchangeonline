# msexchangeonline_external_in_outlook (Resource)

Manages the External tag that Outlook shows on messages from senders outside the organization (`Set-ExternalInOutlook`). This is a singleton: there is exactly one per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange.

## Example Usage

```terraform
# Show the External tag, except for a partner domain.
resource "msexchangeonline_external_in_outlook" "this" {
  enabled    = true
  allow_list = ["partner.example"]
}
```

The resource is a singleton. Import it with the ID `default`:


