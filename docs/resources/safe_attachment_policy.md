# msexchangeonline_safe_attachment_policy (Resource)

Manages a Defender for Office 365 Safe Attachments policy and its associated rule. The policy holds the attachment scanning settings; the rule defines which recipients it applies to. The rule exists only while one of `recipient_domain_is` or `sent_to_member_of` is set. Without one, the policy has no rule of its own and can be scoped by a standalone `msexchangeonline_safe_attachment_rule` resource instead: Exchange links a policy to at most one rule.

## Example Usage

```terraform
# Dynamic Delivery — scan attachments without delaying message delivery
resource "msexchangeonline_safe_attachment_policy" "standard" {
  name = "Standard-SafeAttachments"

  # DynamicDelivery delivers the message immediately with a placeholder;
  # the real attachment is swapped back in once scanning completes
  safe_attachment_action = "DynamicDelivery"

  recipient_domain_is = ["contoso.com"]
  priority            = 0
}

# Strict policy for executives: messages with malicious attachments are blocked
resource "msexchangeonline_safe_attachment_policy" "strict" {
  name = "Strict-SafeAttachments-Executives"

  safe_attachment_action = "Block"

  recipient_domain_is = ["executives.contoso.com"]
  priority            = 0
}
```

## Schema

### Required

- `name` (String) The name of the Safe Attachments policy. Immutable after creation.

### Optional

- `enabled` (Boolean) Whether the associated rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude messages sent to recipients in these domains.
- `priority` (Number) Priority of the associated rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority. Only applies when a recipient condition is set.
- `quarantine_tag` (String) The quarantine policy tag applied to quarantined messages. Leave empty to use the organization default.
- `recipient_domain_is` (List of String) Apply this policy to messages sent to recipients in these domains.
- `redirect` (Boolean) Redirect messages with detected malicious attachments to another email address.
- `redirect_address` (String) Email address to redirect messages to when `redirect` is `true`.
- `safe_attachment_action` (String) Response to attachments with unknown malware, as in the Microsoft Defender portal. Valid values: `Off` (attachments are not scanned), `Allow` (Monitor in the portal: deliver and track the scan results), `Block`, `DynamicDelivery`. `Off` sets the cmdlet's `-Enable` to `$false`; the other values set it to `$true` with `-Action`.
- `sent_to_member_of` (List of String) Apply this policy to messages sent to members of these distribution groups.

### Read-Only

- `id` (String) The unique identifier of the Safe Attachments policy.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. The tenant needs a Microsoft Defender for Office 365 (Plan 1 or 2) license. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the exact policy name as it appears in Exchange Online:

```terraform
import {
  to = msexchangeonline_safe_attachment_policy.example
  id = "Policy Name"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_safe_attachment_policy.example
  identity = { id = "Policy Name" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_safe_attachment_policy.example "Policy Name"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
