# msexchangeonline_outbound_spam_filter_policy (Resource)

Manages an Exchange Online outbound spam filter policy and its associated rule. It controls outbound sending limits and automatic forwarding; the rule defines which senders it applies to. The rule exists only while one of `sender_domain_is`, `from` or `from_member_of` is set. Without one, the policy has no rule of its own and can be scoped by a standalone `msexchangeonline_hosted_outbound_spam_filter_rule` resource instead: Exchange links a policy to at most one rule.

## Example Usage

```terraform
resource "msexchangeonline_outbound_spam_filter_policy" "strict" {
  name                          = "Strict Outbound Spam Policy"
  action_when_threshold_reached = "BlockUser"
  auto_forwarding_mode          = "Off"

  recipient_limit_external_per_hour = 500
  recipient_limit_internal_per_hour = 1000
  recipient_limit_per_day           = 1000

  notify_outbound_spam            = true
  notify_outbound_spam_recipients = ["security@contoso.com"]

  priority = 1
  enabled  = true

  sender_domain_is = ["contoso.com"]
}
```

## Schema

### Required

- `name` (String) Name of the outbound spam filter policy.

### Optional

- `action_when_threshold_reached` (String) Action when a sending limit is exceeded. Valid values: `Alert`, `BlockUser`, `BlockUserForToday`.
- `auto_forwarding_mode` (String) Controls automatic email forwarding. Valid values: `Automatic`, `On`, `Off`.
- `bcc_suspicious_outbound_additional_recipients` (List of String) BCC recipients for suspicious outbound mail.
- `bcc_suspicious_outbound_mail` (Boolean) BCC suspicious outbound messages to the specified recipients.
- `enabled` (Boolean) Whether the associated rule is enabled.
- `from` (List of String) Rule condition: apply this policy to these senders (email addresses or mailbox identities).
- `from_member_of` (List of String) Rule condition: apply this policy to senders who are members of these groups.
- `notify_outbound_spam` (Boolean) Send notifications when a sender is blocked for outbound spam.
- `notify_outbound_spam_recipients` (List of String) Email addresses to notify when a sender is blocked.
- `priority` (Number) Priority of the associated rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority. Only applies when a sender condition is set.
- `recipient_limit_external_per_hour` (Number) Maximum recipients per hour for external messages. `0` = service default.
- `recipient_limit_internal_per_hour` (Number) Maximum recipients per hour for internal messages. `0` = service default.
- `recipient_limit_per_day` (Number) Maximum total recipients per day. `0` = service default.
- `sender_domain_is` (List of String) Rule condition: apply this policy to senders in these domains.

### Read-Only

- `id` (String) The unique identifier of the outbound spam filter policy.
