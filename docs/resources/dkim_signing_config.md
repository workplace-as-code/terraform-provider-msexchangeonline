# msexchangeonline_dkim_signing_config (Resource)

Manages DKIM signing configuration for an Exchange Online accepted domain. A DKIM configuration cannot be deleted: creating the resource adopts the existing configuration of the domain when there is one, and destroying it disables DKIM signing for the domain.

## Example Usage

```terraform
resource "msexchangeonline_dkim_signing_config" "contoso_com" {
  domain_name             = "contoso.com"
  enabled                 = true
  key_size                = 2048
  header_canonicalization = "Relaxed"
  body_canonicalization   = "Relaxed"
}

# After applying, publish these CNAME values in your DNS zone:
output "dkim_cname_selector1" {
  description = "Publish this CNAME in DNS for selector1._domainkey.contoso.com"
  value       = msexchangeonline_dkim_signing_config.contoso_com.selector1_cname
}

output "dkim_cname_selector2" {
  description = "Publish this CNAME in DNS for selector2._domainkey.contoso.com"
  value       = msexchangeonline_dkim_signing_config.contoso_com.selector2_cname
}
```

## Schema

### Required

- `domain_name` (String) The accepted domain to configure DKIM signing for (e.g. `contoso.com`).

### Optional

- `body_canonicalization` (String) Body canonicalization algorithm. Valid values: `Relaxed`, `Simple`.
- `enabled` (Boolean) Whether DKIM signing is enabled for the domain.
- `header_canonicalization` (String) Header canonicalization algorithm. Valid values: `Relaxed`, `Simple`.
- `key_size` (Number) DKIM key size in bits. Valid values: `1024`, `2048`. Reads as the key size of the selector in use after the last rotation, `0` when Exchange reports none. Only applies when the provider creates the configuration: Exchange cannot change the key size of an existing one, so a different value fails (rotate the key with `Rotate-DkimSigningConfig -KeySize`).

### Read-Only

- `id` (String) The unique identifier (same as `domain_name`).
- `selector1_cname` (String) CNAME value to publish in DNS for selector 1 (read-only, set by Exchange Online).
- `selector2_cname` (String) CNAME value to publish in DNS for selector 2 (read-only, set by Exchange Online).

## Import

Import using the domain name:

```terraform
import {
  to = msexchangeonline_dkim_signing_config.example
  id = "contoso.com"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_dkim_signing_config.example
  identity = { id = "contoso.com" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_dkim_signing_config.example "contoso.com"
```
