# msexchangeonline_inbound_connector (Resource)

Manages an Exchange Online inbound connector. Inbound connectors control how Exchange Online receives email from external systems such as on-premises Exchange servers or partner organizations.

## Example Usage

```terraform
# Hybrid on-premises inbound connector
resource "msexchangeonline_inbound_connector" "onprem" {
  name           = "From On-Premises"
  enabled        = true
  connector_type = "OnPremises"

  sender_ip_addresses = ["203.0.113.10/32"]
  require_tls         = true
  comment             = "Inbound connector for Exchange hybrid deployment"
}

# Partner organization inbound connector with certificate validation
resource "msexchangeonline_inbound_connector" "partner" {
  name           = "From Partner Org"
  enabled        = true
  connector_type = "Partner"

  sender_domains                  = ["partner.com"]
  require_tls                     = true
  restrict_domains_to_certificate = true
  tls_sender_certificate_name     = "mail.partner.com"
  comment                         = "Enforced TLS from partner.com"
}
```

## Schema

### Required

- `name` (String) The name of the inbound connector. Immutable after creation.

### Optional

- `comment` (String) Optional description of the connector.
- `connector_type` (String) The type of the connector. Valid values: `OnPremises`, `Partner`.
- `enabled` (Boolean) Whether the connector is enabled.
- `require_tls` (Boolean) Require TLS for inbound connections.
- `restrict_domains_to_certificate` (Boolean) Verify that the TLS certificate used by the sender matches `tls_sender_certificate_name`.
- `sender_domains` (List of String) Domain names from which this connector accepts messages (e.g. `contoso.com`). Required for `Partner` connectors.
- `sender_ip_addresses` (List of String) IP addresses or ranges from which this connector accepts messages (e.g. `203.0.113.0/24`). Typically used for `OnPremises` connectors.
- `tls_sender_certificate_name` (String) The certificate subject expected from the sending server when `restrict_domains_to_certificate = true`.

### Read-Only

- `connector_source` (String) Read-only. How the connector was created. Values: `Default`, `HybridWizard`, `AdminUI`.
- `id` (String) The unique identifier of the inbound connector.
