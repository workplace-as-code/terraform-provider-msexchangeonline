# msexchangeonline_transport_config (Resource)

Manages the organization-wide transport settings (`Set-TransportConfig`). This is a singleton: there is exactly one per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange.

## Example Usage

```terraform
# Disable SMTP AUTH and legacy TLS, keep reply-all storm protection.
resource "msexchangeonline_transport_config" "this" {
  smtp_client_authentication_disabled = true
  allow_legacy_tls_clients            = false
  reply_all_storm_protection_enabled  = true
}
```

## Schema

### Optional

- `address_book_policy_routing_enabled` (Boolean) Resolve recipients to the global address list of the sender's address book policy.
- `allow_legacy_tls_clients` (Boolean) Allow TLS 1.0 and 1.1 clients to connect with SMTP AUTH.
- `convert_disclaimer_wrapper_to_eml` (Boolean) Attach the original message as an .eml file when a transport rule disclaimer cannot be inserted.
- `external_postmaster_address` (String) Sender address of the delivery status notifications sent to external senders.
- `journaling_report_ndr_to` (String) Address that receives the journal reports that cannot be delivered, required before journal rules deliver anything. It cannot be an Exchange Online mailbox. Once set, it can be changed but never cleared.
- `reply_all_storm_block_duration_hours` (Number) Hours during which further reply-all messages are blocked.
- `reply_all_storm_detection_minimum_recipients` (Number) Minimum number of recipients for a thread to be considered a reply-all storm.
- `reply_all_storm_detection_minimum_replies` (Number) Minimum number of reply-all messages, within 60 minutes, to detect a storm.
- `reply_all_storm_protection_enabled` (Boolean) Block reply-all storms.
- `rfc2231_encoding_enabled` (Boolean) Encode attachment names with RFC 2231.
- `smtp_client_authentication_disabled` (Boolean) Disable SMTP AUTH client submission (port 587) for the whole organization. Mailboxes can still enable it individually.

### Read-Only

- `id` (String) Always `default`.

## Import

The resource is a singleton. Import it with the ID `default`:

```terraform
import {
  to = msexchangeonline_transport_config.this
  id = "default"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_transport_config.this
  identity = { id = "default" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_transport_config.this "default"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
