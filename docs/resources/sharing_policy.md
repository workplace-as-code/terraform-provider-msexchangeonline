# msexchangeonline_sharing_policy (Resource)

Manages a sharing policy, which sets the calendar and contact information users can share with people outside the organization (`New-SharingPolicy`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `domains` is required to create a policy. Mailboxes without a sharing policy of their own use the default one, `Default Sharing Policy`: import it to restrict sharing for the whole organization.

## Example Usage

```terraform
# Partners see free/busy times only; no anonymous calendar links.
resource "msexchangeonline_sharing_policy" "partners" {
  name = "Partners"
  domains = [
    "contoso.com:CalendarSharingFreeBusySimple",
    "fabrikam.com:CalendarSharingFreeBusyDetail,ContactsSharing",
  ]
}

# The policy of every mailbox without one of its own.
resource "msexchangeonline_sharing_policy" "default" {
  name    = "Default Sharing Policy"
  domains = ["*:CalendarSharingFreeBusySimple"]
}

import {
  to = msexchangeonline_sharing_policy.default
  id = "Default Sharing Policy"
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `domains` (List of String) Domains and what users can share with them, as `domain:Action` or `domain:Action,Action` without spaces. The domain is a domain name (subdomains are not included), `*` for every federated organization or `Anonymous` for anyone with a link. Actions: `CalendarSharingFreeBusySimple`, `CalendarSharingFreeBusyDetail`, `CalendarSharingFreeBusyReviewer`, `ContactsSharing`.
- `enabled` (Boolean) Whether the policy applies. Mailboxes keep sharing until the sharing policy assistant next processes them.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's app registration needs the sharing policy cmdlets of the **Federated Sharing** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only the sharing policy and organization relationship cmdlets: the built-in role can also change the federation trust. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the policy name:

```terraform
import {
  to = msexchangeonline_sharing_policy.partners
  id = "Partners"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_sharing_policy.partners
  identity = { id = "Partners" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_sharing_policy.partners "Partners"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
