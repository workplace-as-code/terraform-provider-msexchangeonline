# msexchangeonline_hosted_connection_filter_policy (Resource)

Manages the connection filter policy, the first layer of Exchange Online Protection: IP addresses whose mail is always accepted or always blocked. Exchange Online has a single connection filter policy, `Default` (`Set-HostedConnectionFilterPolicy`). This is a singleton: there is exactly one per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange.

## Example Usage

```terraform
# Always accept mail from the on-premises relay, always reject a known spam
# source.
resource "msexchangeonline_hosted_connection_filter_policy" "this" {
  ip_allow_list    = ["203.0.113.10"]
  ip_block_list    = ["198.51.100.0/24"]
  enable_safe_list = false
}
```

## Schema

### Optional

- `enable_safe_list` (Boolean) Also skip spam filtering for senders on the Microsoft safe list.
- `ip_allow_list` (List of String) IP addresses or CIDR ranges (/24 to /32) whose mail skips spam filtering.
- `ip_block_list` (List of String) IP addresses or CIDR ranges (/24 to /32) whose mail is always rejected.

### Read-Only

- `id` (String) Always `Default`.

## Import

The resource is a singleton. Import it with the ID `Default`:

```terraform
import {
  to = msexchangeonline_hosted_connection_filter_policy.this
  id = "Default"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_hosted_connection_filter_policy.this
  identity = { id = "Default" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_hosted_connection_filter_policy.this "Default"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
