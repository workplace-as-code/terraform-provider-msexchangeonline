# msexchangeonline_offline_address_book (Resource)

Manages an offline address book (OAB), the address lists Outlook downloads for offline use (`New-OfflineAddressBook`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. Which offline address book is the default is not managed.

## Example Usage

```terraform
resource "msexchangeonline_global_address_list" "contoso" {
  name             = "Contoso - GAL"
  recipient_filter = "CustomAttribute1 -eq 'Contoso'"
}

# The offline address book of the Contoso entity: its GAL.
resource "msexchangeonline_offline_address_book" "contoso" {
  name          = "Contoso - OAB"
  address_lists = [msexchangeonline_global_address_list.contoso.name]
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `address_lists` (Set of String) Names of the address lists in the offline address book, usually the GAL of an address book policy. Required to create it.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's app registration needs the offline address book cmdlets of the **Address Lists** Exchange management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes. Exchange Online does not give this role to Organization Management by default. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the offline address book name:

```terraform
import {
  to = msexchangeonline_offline_address_book.contoso
  id = "Contoso - OAB"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_offline_address_book.contoso
  identity = { id = "Contoso - OAB" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_offline_address_book.contoso "Contoso - OAB"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
