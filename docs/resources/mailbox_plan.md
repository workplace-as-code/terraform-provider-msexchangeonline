# msexchangeonline_mailbox_plan (Resource)

Manages a mailbox plan: the size limits and deleted item retention that new mailboxes get from their license. Existing mailboxes keep their settings (`Set-MailboxPlan`). The object cannot be created: the resource adopts the existing one. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. `name` is the display name of the plan, the same in every tenant, for example `ExchangeOnlineEnterprise` (Exchange Online Plan 2), `ExchangeOnline` (Plan 1), `ExchangeOnlineDeskless` (Kiosk) or `ExchangeOnlineEssentials`. Sizes are in megabytes and cannot exceed what the license allows.

## Example Usage

```terraform
# New Exchange Online Plan 2 mailboxes: 50 MB messages, 30 days to recover items.
resource "msexchangeonline_mailbox_plan" "enterprise" {
  name                          = "ExchangeOnlineEnterprise"
  max_send_size_mb              = 50
  max_receive_size_mb           = 50
  retain_deleted_items_for_days = 30
}
```

## Schema

### Required

- `name` (String) The name of the existing object. Changing it adopts another object and leaves this one as it is.

### Optional

- `issue_warning_quota_mb` (Number) Mailbox size, in MB, at which the user is warned.
- `max_receive_size_mb` (Number) Largest message a new mailbox can receive, in MB (up to 150).
- `max_send_size_mb` (Number) Largest message a new mailbox can send, in MB (up to 150).
- `prohibit_send_quota_mb` (Number) Mailbox size, in MB, at which the user can no longer send.
- `prohibit_send_receive_quota_mb` (Number) Mailbox size, in MB, at which the mailbox can no longer send or receive.
- `retain_deleted_items_for_days` (Number) Days deleted items can be recovered (up to 30).
- `retention_policy` (String) Retention policy of new mailboxes, by name.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's app registration needs the mailbox plan cmdlets of the **Mail Recipients** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only the `Get-` and `Set-` cmdlets of mailbox plans and CAS mailbox plans: the built-in role can also change every mailbox, user and group. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the display name of the plan:

```terraform
import {
  to = msexchangeonline_mailbox_plan.enterprise
  id = "ExchangeOnlineEnterprise"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_mailbox_plan.enterprise
  identity = { id = "ExchangeOnlineEnterprise" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_mailbox_plan.enterprise "ExchangeOnlineEnterprise"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
