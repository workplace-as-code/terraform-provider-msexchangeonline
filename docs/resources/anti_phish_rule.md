# msexchangeonline_anti_phish_rule (Resource)

Manages a standalone Exchange Online anti-phishing rule. Use this resource to link an existing `msexchangeonline_anti_phish_policy` to a specific set of recipients without managing the policy settings. Useful when multiple recipient groups need different scoping on the same policy.

## Example Usage

```terraform
# The policy sets no recipient condition, so it has no rule of its own: the
# standalone rule below scopes it. Exchange links a policy to at most one rule.
resource "msexchangeonline_anti_phish_policy" "strict" {
  name                      = "Strict Anti-Phish"
  phish_threshold_level     = 2
  enable_spoof_intelligence = true
}

resource "msexchangeonline_anti_phish_rule" "executives" {
  name              = "Anti-Phish Rule - Executives"
  anti_phish_policy = msexchangeonline_anti_phish_policy.strict.name
  priority          = 1
  enabled           = true

  sent_to_member_of = ["executives@contoso.com"]
}
```

## Schema

### Required

- `anti_phish_policy` (String) The name of the anti-phishing policy this rule applies. The policy must exist before the rule is created.
- `name` (String) The name of the rule. Must be unique. Immutable after creation.

### Optional

- `enabled` (Boolean) Whether the rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude messages sent to recipients in these domains.
- `except_if_sent_to` (List of String) Exclude messages sent to these specific recipients.
- `priority` (Number) Priority of the rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority.
- `recipient_domain_is` (List of String) Apply this rule to messages sent to recipients in these domains.
- `sent_to` (List of String) Apply this rule to messages sent to these specific recipients (email addresses).
- `sent_to_member_of` (List of String) Apply this rule to messages sent to members of these distribution groups.

### Read-Only

- `id` (String) The unique identifier of the anti-phishing rule.

## Import

Import using the rule name:

```terraform
import {
  to = msexchangeonline_anti_phish_rule.example

}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
```
