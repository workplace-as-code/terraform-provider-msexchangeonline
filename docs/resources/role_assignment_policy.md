# msexchangeonline_role_assignment_policy (Resource)

Manages a role assignment policy (`New-RoleAssignmentPolicy`): the end-user roles that set what users can change on their own mailbox, such as their contact information or their distribution groups. Assigning the policy to mailboxes is not managed; mailboxes without a policy of their own use the default one.

## Example Usage

```terraform
# Users can change their options but not their distribution groups
resource "msexchangeonline_role_assignment_policy" "default" {
  name  = "Default Role Assignment Policy"
  roles = ["MyBaseOptions", "MyContactInformation", "MyProfileInformation", "MyRetentionPolicies"]
}
```

## Schema

### Required

- `name` (String) Name of the policy, for example `Default Role Assignment Policy`. Changing it creates a new policy.
- `roles` (Set of String) End-user roles of the policy, for example `MyBaseOptions`, `MyContactInformation`, `MyDistributionGroupMembership`. A role left out is removed from the policy.

### Optional

- `description` (String) Description of the policy.
- `is_default` (Boolean) Whether new mailboxes get this policy. Making a policy the default removes the flag from the previous default policy.

### Read-Only

- `id` (String) The policy name.

## Default policy

Mailboxes without a policy of their own use the default policy, `Default Role Assignment Policy`: import
it to restrict what every user can change. `is_default = true` on another policy makes the previous
default drift (its `is_default` becomes `false`): manage both policies, or neither flag. A policy that is
the default or that mailboxes use cannot be deleted. Assigning a policy to mailboxes is not managed.

## Permissions

The provider's app registration needs the **Role Management** Exchange management role, which lets it grant itself any other role: give it only to the pipeline that manages the Exchange delegation. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it with `-IncludeRoleManagement`. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).
