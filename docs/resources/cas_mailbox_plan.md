# msexchangeonline_cas_mailbox_plan (Resource)

Manages a CAS mailbox plan: the client protocols that new mailboxes get from their license. Existing mailboxes keep their settings (`Set-CASMailboxPlan`). The object cannot be created: the resource adopts the existing one. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange. `name` is the display name of the plan, the same in every tenant, for example `ExchangeOnlineEnterprise` (Exchange Online Plan 2), `ExchangeOnline` (Plan 1), `ExchangeOnlineDeskless` (Kiosk) or `ExchangeOnlineEssentials`.

## Example Usage

```terraform
# New Exchange Online Plan 2 mailboxes start without POP, IMAP or EWS.
resource "msexchangeonline_cas_mailbox_plan" "enterprise" {
  name         = "ExchangeOnlineEnterprise"
  pop_enabled  = false
  imap_enabled = false
  ews_enabled  = false
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `active_sync_enabled` (Boolean) Allow Exchange ActiveSync.
- `ews_enabled` (Boolean) Allow Exchange Web Services.
- `imap_enabled` (Boolean) Allow IMAP4.
- `mapi_enabled` (Boolean) Allow MAPI clients such as Outlook for Windows.
- `owa_enabled` (Boolean) Allow Outlook on the web.
- `owa_mailbox_policy` (String) Outlook on the web mailbox policy, by name.
- `pop_enabled` (Boolean) Allow POP3.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's app registration needs the mailbox plan cmdlets of the **Mail Recipients** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only the `Get-` and `Set-` cmdlets of mailbox plans and CAS mailbox plans: the built-in role can also change every mailbox, user and group. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the display name of the plan:

```terraform
import {
  to = msexchangeonline_cas_mailbox_plan.enterprise
  id = "ExchangeOnlineEnterprise"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_cas_mailbox_plan.enterprise
  identity = { id = "ExchangeOnlineEnterprise" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_cas_mailbox_plan.enterprise "ExchangeOnlineEnterprise"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
