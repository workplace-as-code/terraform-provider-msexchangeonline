# msexchangeonline_hosted_content_filter_rule (Resource)

Manages a standalone hosted content filter rule (spam filter rule). Use this when the policy is managed separately via `msexchangeonline_hosted_content_filter_policy`.

## Example Usage

```terraform
# The policy sets no recipient condition, so it has no rule of its own: the
# standalone rule below scopes it. Exchange links a policy to at most one rule.
resource "msexchangeonline_hosted_content_filter_policy" "strict" {
  name           = "Strict Spam Filter"
  spam_action    = "Quarantine"
  bulk_threshold = 4
}

resource "msexchangeonline_hosted_content_filter_rule" "all_users" {
  name                         = "Strict Spam Filter Rule"
  hosted_content_filter_policy = msexchangeonline_hosted_content_filter_policy.strict.name
  priority                     = 1
  enabled                      = true

  recipient_domain_is = ["contoso.com"]
}
```

## Schema

### Required

- `hosted_content_filter_policy` (String) Name of the hosted content filter policy this rule applies.
- `name` (String) Name of the hosted content filter rule.

### Optional

- `enabled` (Boolean) Whether the rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude recipients in these domains.
- `priority` (Number) Priority of the rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority.
- `recipient_domain_is` (List of String) Apply this rule to recipients in these domains.
- `sent_to_member_of` (List of String) Apply this rule to members of these groups.

### Read-Only

- `id` (String) The unique identifier of the spam filter rule.

## Import

Import using the rule name:

```terraform
import {
  to = msexchangeonline_hosted_content_filter_rule.example
  id = "Strict Spam Filter Rule"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_hosted_content_filter_rule.example
  identity = { id = "Strict Spam Filter Rule" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_hosted_content_filter_rule.example "Strict Spam Filter Rule"
```
