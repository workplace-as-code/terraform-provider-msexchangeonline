# msexchangeonline_anti_phish_policy (Resource)

Manages an Exchange Online anti-phishing policy and its associated rule (Exchange Online Protection; the impersonation and mailbox intelligence settings need Defender for Office 365). The policy holds the security settings; the rule defines which recipients it applies to. The rule exists only while one of `recipient_domain_is` or `sent_to_member_of` is set. Without one, the policy has no rule of its own and can be scoped by a standalone `msexchangeonline_anti_phish_rule` resource instead: Exchange links a policy to at most one rule.

## Example Usage

```terraform
# Strict anti-phishing policy for executives and finance team
resource "msexchangeonline_anti_phish_policy" "strict" {
  name = "Strict-AntiPhish-Executives"

  # Aggressive detection threshold
  phish_threshold_level = 3

  # Spoof intelligence
  enable_spoof_intelligence  = true
  authentication_fail_action = "Quarantine"

  # Mailbox intelligence (AI-based impersonation detection)
  enable_mailbox_intelligence            = true
  enable_mailbox_intelligence_protection = true
  mailbox_intelligence_protection_action = "Quarantine"

  # Protect the organization's own domains from impersonation
  enable_organization_domains_protection = true

  # Visual indicators in Outlook
  enable_unauthenticated_sender    = true
  enable_via_tag                   = true
  enable_first_contact_safety_tips = true

  # Apply to the finance and executive domains
  recipient_domain_is = ["finance.contoso.com", "executives.contoso.com"]
  priority            = 0
}

# Standard anti-phishing policy for all other users
resource "msexchangeonline_anti_phish_policy" "standard" {
  name = "Standard-AntiPhish"

  phish_threshold_level      = 1
  enable_spoof_intelligence  = true
  authentication_fail_action = "MoveToJmf"

  enable_mailbox_intelligence = true

  enable_unauthenticated_sender = true
  enable_via_tag                = true

  recipient_domain_is = ["contoso.com"]
  priority            = 1
}
```

## Schema

### Required

- `name` (String) The name of the anti-phishing policy. Immutable after creation.

### Optional

- `authentication_fail_action` (String) Action for messages that fail authentication checks. Valid values: `MoveToJmf`, `Redirect`, `Quarantine`, `Delete`, `BccMessage`.
- `enable_first_contact_safety_tips` (Boolean) Show a safety tip when a user receives an email from a sender they haven't contacted before.
- `enable_mailbox_intelligence` (Boolean) Enable mailbox intelligence to improve impersonation detection based on user email patterns. Needs Microsoft Defender for Office 365.
- `enable_mailbox_intelligence_protection` (Boolean) Enable mailbox intelligence protection actions. Requires `enable_mailbox_intelligence = true`. Needs Microsoft Defender for Office 365.
- `enable_organization_domains_protection` (Boolean) Protect the organization's own domains from impersonation attacks. Needs Microsoft Defender for Office 365.
- `enable_spoof_intelligence` (Boolean) Enable spoof intelligence to detect and block spoofed senders.
- `enable_unauthenticated_sender` (Boolean) Show a `?` symbol in Outlook when the sender cannot be authenticated.
- `enable_via_tag` (Boolean) Show a `via` tag in Outlook when the sender address differs from the DKIM signature or MAIL FROM address.
- `enabled` (Boolean) Whether the associated rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude messages sent to recipients in these domains.
- `mailbox_intelligence_protection_action` (String) Action for messages detected via mailbox intelligence. Valid values: `NoAction`, `MoveToJmf`, `Redirect`, `Quarantine`, `Delete`, `BccMessage`. Needs Microsoft Defender for Office 365.
- `phish_threshold_level` (Number) Aggressiveness of phishing detection. `1` = Standard, `2` = Aggressive, `3` = More aggressive, `4` = Most aggressive. Needs Microsoft Defender for Office 365.
- `priority` (Number) Priority of the associated rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority. Only applies when a recipient condition is set.
- `recipient_domain_is` (List of String) Apply this policy to messages sent to recipients in these domains.
- `sent_to_member_of` (List of String) Apply this policy to messages sent to members of these distribution groups.

### Read-Only

- `id` (String) The unique identifier of the anti-phishing policy.

## Import

Import using the exact policy name as it appears in Exchange Online:

```terraform
import {
  to = msexchangeonline_anti_phish_policy.example
  id = "Policy Name"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_anti_phish_policy.example
  identity = { id = "Policy Name" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_anti_phish_policy.example "Policy Name"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
