# msexchangeonline_safe_links_rule (Resource)

Manages a standalone Safe Links rule. Use this when the Safe Links policy is managed separately via `msexchangeonline_safe_links_policy`.

## Example Usage

```terraform
# The policy sets no recipient condition, so it has no rule of its own: the
# standalone rule below scopes it. Exchange links a policy to at most one rule.
resource "msexchangeonline_safe_links_policy" "strict" {
  name                         = "Strict Safe Links"
  enable_safe_links_for_email  = true
  enable_safe_links_for_office = true
  enable_safe_links_for_teams  = true
  track_clicks                 = true
  allow_click_through          = false
  scan_urls                    = true
  deliver_message_after_scan   = true
}

resource "msexchangeonline_safe_links_rule" "all_users" {
  name              = "Safe Links Rule - All Users"
  safe_links_policy = msexchangeonline_safe_links_policy.strict.name
  priority          = 1
  enabled           = true

  recipient_domain_is = ["contoso.com"]
}
```

## Schema

### Required

- `name` (String) Name of the Safe Links rule.
- `safe_links_policy` (String) Name of the Safe Links policy this rule applies.

### Optional

- `enabled` (Boolean) Whether the rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude recipients in these domains.
- `priority` (Number) Priority of the rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority.
- `recipient_domain_is` (List of String) Apply this rule to recipients in these domains.
- `sent_to_member_of` (List of String) Apply this rule to members of these distribution groups.

### Read-Only

- `id` (String) The unique identifier of the Safe Links rule.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. The tenant needs a Microsoft Defender for Office 365 (Plan 1 or 2) license. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the rule name:

```terraform
import {
  to = msexchangeonline_safe_links_rule.example
  id = "Safe Links Rule - All Users"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_safe_links_rule.example
  identity = { id = "Safe Links Rule - All Users" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_safe_links_rule.example "Safe Links Rule - All Users"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
