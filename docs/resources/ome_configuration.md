# msexchangeonline_ome_configuration (Resource)

Manages a branding template of Microsoft Purview Message Encryption: the logo, colors and texts of encrypted messages and of the encrypted message portal (`New-OMEConfiguration`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `name = "OME Configuration"` adopts the default template: it is changed, never created, and destroying the resource only removes it from the state. Other names are custom templates, which need Advanced Message Encryption (E5); a transport rule applies them with `apply_rights_protection_customization_template`.

## Example Usage

```terraform
# The default template, with the company logo
resource "msexchangeonline_ome_configuration" "default" {
  name             = "OME Configuration"
  image            = filebase64("${path.module}/logo.png")
  background_color = "#ffffff"
  disclaimer_text  = "This message is confidential."
}

# A custom template whose messages expire after 30 days
resource "msexchangeonline_ome_configuration" "finance" {
  name                         = "Finance"
  image                        = filebase64("${path.module}/logo.png")
  introduction_text            = "has sent you a secure message from Contoso Finance."
  external_mail_expiry_in_days = 30
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `background_color` (String) Background color, as an HTML name or a hex code such as `#ffffff`.
- `disclaimer_text` (String) Disclaimer at the bottom of the message.
- `email_text` (String) Text of the message the recipient receives.
- `external_mail_expiry_in_days` (Number) Days external recipients can read the message in the portal, from 1 to 730; `0` for no expiry. Custom templates only.
- `image` (String) Logo, as base64 (`filebase64("logo.png")`): PNG, JPG, BMP or TIFF, ideally under 40 KB and 170 x 70 pixels. `""` removes the logo. Exchange re-encodes the image: the configured value is kept as long as Exchange returns the image it stored at the last write.
- `introduction_text` (String) Text after the sender's name and address.
- `otp_enabled` (Boolean) Let recipients sign in to the portal with a one-time passcode.
- `portal_text` (String) Text at the top of the encrypted message portal.
- `privacy_statement_url` (String) Address of the privacy statement link.
- `read_button_text` (String) Text of the Read the message button.
- `social_id_sign_in` (Boolean) Let recipients sign in with a Microsoft, Google or Yahoo account.

### Read-Only

- `id` (String) The object name (same as `name`).

## Default and custom templates

`OME Configuration` is the default template of every tenant: Microsoft Purview Message Encryption uses it
when a transport rule names no other template. Custom templates need Advanced Message Encryption
(Microsoft 365 E5 or the add-on), as does `external_mail_expiry_in_days`. Apply a template to messages with a
transport rule. Exchange applies a branding template only to messages sent from inside the organization:

```terraform
resource "msexchangeonline_transport_rule" "encrypt_finance" {
  name                                           = "Encrypt finance mail"
  from_scope                                     = "InOrganization"
  subject_or_body_contains_words                 = ["[secure]"]
  apply_rights_protection_template               = "Encrypt"
  apply_rights_protection_customization_template = msexchangeonline_ome_configuration.finance.name
}
```

## Import

Import using the template name:

```terraform
import {
  to = msexchangeonline_ome_configuration.finance
  id = "Finance"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_ome_configuration.finance
  identity = { id = "Finance" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_ome_configuration.finance "Finance"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
