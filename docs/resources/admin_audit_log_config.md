# msexchangeonline_admin_audit_log_config (Resource)

Manages the recording of user and admin activities in the Microsoft 365 unified audit log (`Set-AdminAuditLogConfig`). This is a singleton: there is exactly one per tenant. Only the attributes set in the configuration are managed; the others keep their current value. Destroying this resource removes it from Terraform state without changing Exchange.

## Example Usage

```terraform
# Keep the unified audit log on.
resource "msexchangeonline_admin_audit_log_config" "this" {
  unified_audit_log_ingestion_enabled = true
}
```

## Schema

### Optional

- `unified_audit_log_ingestion_enabled` (Boolean) Record user and admin activities in the unified audit log. A change can take up to 60 minutes to apply.

### Read-Only

- `id` (String) Always `default`.

## Permissions

The provider's app registration needs the `Get-AdminAuditLogConfig` and `Set-AdminAuditLogConfig` cmdlets of the **Audit Logs** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only these cmdlets: the built-in role can also search the whole audit log and exclude mailboxes from it. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

The resource is a singleton. Import it with the ID `default`:

```terraform
import {
  to = msexchangeonline_admin_audit_log_config.this
  id = "default"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_admin_audit_log_config.this
  identity = { id = "default" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_admin_audit_log_config.this "default"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
