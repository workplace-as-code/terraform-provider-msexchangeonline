# msexchangeonline_organization_relationship (Resource)

Manages an organization relationship, which shares free/busy information, MailTips and photos with another Microsoft 365 organization or an on-premises Exchange organization (`New-OrganizationRelationship`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `domain_names` is required to create a relationship. Get the `target_*` values of the other organization with `Get-FederationInformation -DomainName <domain>`. The mailbox move settings of cross-tenant migrations are not managed.

## Example Usage

```terraform
# Free/busy times with a subsidiary on another Microsoft 365 tenant. The target
# values come from Get-FederationInformation -DomainName fabrikam.com.
locals {
  autodiscover = "https://autodiscover-s.outlook.com/autodiscover/autodiscover.svc/WSSecurity"
}

resource "msexchangeonline_organization_relationship" "fabrikam" {
  name                     = "Fabrikam"
  domain_names             = ["fabrikam.com", "fabrikam.mail.onmicrosoft.com"]
  free_busy_access_enabled = true
  free_busy_access_level   = "AvailabilityOnly"
  target_application_uri   = "outlook.com"
  target_autodiscover_epr  = local.autodiscover
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `archive_access_enabled` (Boolean) The other organization hosts the cloud archives of this organization's mailboxes (hybrid).
- `delivery_report_enabled` (Boolean) Share delivery reports with the other organization.
- `domain_names` (Set of String) Domains of the other organization.
- `enabled` (Boolean) Whether the relationship is used.
- `free_busy_access_enabled` (Boolean) Share free/busy information with the other organization.
- `free_busy_access_level` (String) Free/busy details shared when `free_busy_access_enabled` is `true`. Valid values: `None`, `AvailabilityOnly`, `LimitedDetails` (case-insensitive).
- `mail_tips_access_enabled` (Boolean) Share MailTips with the other organization.
- `mail_tips_access_level` (String) MailTips shared when `mail_tips_access_enabled` is `true`. Valid values: `None`, `Limited`, `All` (case-insensitive).
- `organization_contact` (String) Email address of a contact in the other organization.
- `photos_enabled` (Boolean) Share user photos with the other organization.
- `target_application_uri` (String) Application URI of the other organization, for example `outlook.com` for Microsoft 365.
- `target_autodiscover_epr` (String) Autodiscover endpoint of the other organization.
- `target_owa_url` (String) Outlook on the web URL of the other organization.
- `target_sharing_epr` (String) Exchange Web Services endpoint of the other organization, when Autodiscover cannot find it.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's app registration needs the organization relationship cmdlets of the **Federated Sharing** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) grants them through a custom role that holds only the sharing policy and organization relationship cmdlets: the built-in role can also change the federation trust. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the relationship name:

```terraform
import {
  to = msexchangeonline_organization_relationship.fabrikam
  id = "Fabrikam"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_organization_relationship.fabrikam
  identity = { id = "Fabrikam" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_organization_relationship.fabrikam "Fabrikam"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
