# msexchangeonline_quarantine_policy (Resource)

Manages an Exchange Online quarantine policy. Quarantine policies define what end users can do with quarantined messages.

## Example Usage

```terraform
# End-users can view and request release
resource "msexchangeonline_quarantine_policy" "user_request" {
  name                                  = "UserRequestRelease"
  end_user_quarantine_permissions_value = 17
  esn_enabled                           = true
  quarantine_retention_days             = 30
}

# Notify-only — security team reviews all releases
resource "msexchangeonline_quarantine_policy" "admin_only" {
  name                                  = "AdminOnlyAccess"
  end_user_quarantine_permissions_value = 0
  esn_enabled                           = false
  quarantine_retention_days             = 30
}

# Full end-user control for low-risk detections
resource "msexchangeonline_quarantine_policy" "full_access" {
  name                                  = "FullAccess"
  end_user_quarantine_permissions_value = 23
  esn_enabled                           = true
  quarantine_retention_days             = 15
}
```

## Schema

### Required

- `name` (String) Name of the quarantine policy.

### Optional

- `end_user_quarantine_permissions_value` (Number) Bitmask integer defining end-user permissions. See Microsoft docs for values (e.g. `17` = view + release request).
- `esn_enabled` (Boolean) Enable end-user spam notifications for this quarantine policy.
- `quarantine_retention_days` (Number) Number of days messages are held in quarantine (1–30).

### Read-Only

- `id` (String) The unique identifier of the quarantine policy.
