# msexchangeonline_address_book_policy (Resource)

Manages an address book policy (ABP), which gives the mailboxes it is assigned to their own GAL, address lists, offline address book and room list (`New-AddressBookPolicy`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. All four references are required to create a policy; they are names of the corresponding resources. Assigning the policy to mailboxes (`Set-Mailbox -AddressBookPolicy`) is not managed.

## Example Usage

```terraform
# Address book segmentation: the mailboxes of the Contoso entity only see the
# recipients of Contoso. Assign the policy to the mailboxes outside Terraform
# (Set-Mailbox -AddressBookPolicy).
resource "msexchangeonline_global_address_list" "contoso" {
  name             = "Contoso - GAL"
  recipient_filter = "CustomAttribute1 -eq 'Contoso'"
}

resource "msexchangeonline_address_list" "contoso_users" {
  name             = "Contoso - Users"
  recipient_filter = "CustomAttribute1 -eq 'Contoso' -and RecipientType -eq 'UserMailbox'"
}

resource "msexchangeonline_address_list" "contoso_rooms" {
  name             = "Contoso - Rooms"
  recipient_filter = "CustomAttribute1 -eq 'Contoso' -and RecipientTypeDetails -eq 'RoomMailbox'"
}

resource "msexchangeonline_offline_address_book" "contoso" {
  name          = "Contoso - OAB"
  address_lists = [msexchangeonline_global_address_list.contoso.name]
}

resource "msexchangeonline_address_book_policy" "contoso" {
  name                 = "Contoso"
  global_address_list  = msexchangeonline_global_address_list.contoso.name
  offline_address_book = msexchangeonline_offline_address_book.contoso.name
  room_list            = msexchangeonline_address_list.contoso_rooms.name
  address_lists        = [msexchangeonline_address_list.contoso_users.name]
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `address_lists` (Set of String) Names of the address lists users see besides the GAL.
- `global_address_list` (String) Name of the global address list.
- `offline_address_book` (String) Name of the offline address book.
- `room_list` (String) Name of the address list of the rooms users can book, an address list whose filter selects room mailboxes.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's app registration needs the address book policy cmdlets of the **Address Lists** Exchange management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes. Exchange Online does not give this role to Organization Management by default. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the policy name:

```terraform
import {
  to = msexchangeonline_address_book_policy.contoso
  id = "Contoso"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_address_book_policy.contoso
  identity = { id = "Contoso" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_address_book_policy.contoso "Contoso"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
