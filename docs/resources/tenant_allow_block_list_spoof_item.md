# msexchangeonline_tenant_allow_block_list_spoof_item (Resource)

Manages a spoofed sender pair of the Tenant Allow/Block List (`New-TenantAllowBlockListSpoofItems`): a spoofed user and the infrastructure sending as that user, allowed or blocked.

## Example Usage

```terraform
# Allow a partner that sends as contoso.com from its own mail servers.
resource "msexchangeonline_tenant_allow_block_list_spoof_item" "partner" {
  spoofed_user           = "contoso.com"
  sending_infrastructure = "mail.fabrikam.com"
  spoof_type             = "External"
  action                 = "Allow"
}
```

## Schema

### Required

- `action` (String) `Allow` or `Block`.
- `sending_infrastructure` (String) Source of the messages: a domain found in the reverse DNS of the sending server, a verified DKIM domain, or an IP address written `<address>/24`. Changing it creates a new entry.
- `spoof_type` (String) `Internal` or `External`. Changing it creates a new entry.
- `spoofed_user` (String) Email address for a sender inside the organization, domain for a sender outside it. Changing it creates a new entry.

### Read-Only

- `id` (String) `<spoof_type>:<spoofed_user>:<sending_infrastructure>`.
