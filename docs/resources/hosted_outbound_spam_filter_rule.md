# msexchangeonline_hosted_outbound_spam_filter_rule (Resource)

Manages a standalone outbound spam filter rule, which applies an outbound spam filter policy to a set of senders. Use it with a `msexchangeonline_outbound_spam_filter_policy` that has no sender condition of its own (`New-HostedOutboundSpamFilterRule`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `hosted_outbound_spam_filter_policy` and at least one of `from`, `from_member_of` or `sender_domain_is` are required to create a rule. A condition left out of the configuration is not managed: set it to `[]` to clear it.

## Example Usage

```terraform
# A strict outbound policy for a sending service, scoped by a standalone rule.
resource "msexchangeonline_outbound_spam_filter_policy" "bulk_senders" {
  name                          = "Bulk senders"
  recipient_limit_per_day       = 2000
  action_when_threshold_reached = "BlockUser"
}

resource "msexchangeonline_hosted_outbound_spam_filter_rule" "bulk_senders" {
  name                               = "Bulk senders"
  hosted_outbound_spam_filter_policy = msexchangeonline_outbound_spam_filter_policy.bulk_senders.name
  from                               = ["newsletter@contoso.com"]
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `comments` (String) Comments about the rule.
- `enabled` (Boolean) Whether the rule is enabled.
- `except_if_from` (List of String) Exception: the sender is one of these addresses or mailboxes.
- `except_if_from_member_of` (List of String) Exception: the sender is a member of one of these groups.
- `except_if_sender_domain_is` (List of String) Exception: the sender's domain is one of these domains.
- `from` (List of String) Condition: the sender is one of these addresses or mailboxes.
- `from_member_of` (List of String) Condition: the sender is a member of one of these groups.
- `hosted_outbound_spam_filter_policy` (String) Name of the outbound spam filter policy the rule applies.
- `priority` (Number) Priority of the rule. `0` is evaluated first.
- `sender_domain_is` (List of String) Condition: the sender's domain is one of these domains.

### Read-Only

- `id` (String) The object name (same as `name`).
