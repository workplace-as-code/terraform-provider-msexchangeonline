# msexchangeonline_role_group (Resource)

Manages a custom role group: an Exchange administration role group whose roles and scopes come from `msexchangeonline_management_role_assignment` (`New-RoleGroup`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. Members and the managers of the membership (ManagedBy) are not managed: they come from your identity management process, and a member added or removed outside Terraform never shows as a change. Built-in role groups (Organization Management, ...) cannot be managed; read them with the data source.

## Example Usage

```terraform
# A help desk role group; its members come from the identity management process
resource "msexchangeonline_role_group" "helpdesk_france" {
  name        = "Helpdesk France"
  description = "First-level support for the French subsidiary"
}
```

## Permissions

The provider's app registration needs the **Role Management** Exchange management role, which lets it grant itself any other role: give it only to the pipeline that manages the Exchange delegation. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it with `-IncludeRoleManagement`. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the role group name:

```terraform
import {
  to = msexchangeonline_role_group.helpdesk_france
  id = "Helpdesk France"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_role_group.helpdesk_france
  identity = { id = "Helpdesk France" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_role_group.helpdesk_france "Helpdesk France"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
