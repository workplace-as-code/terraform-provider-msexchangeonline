# msexchangeonline_journal_rule (Resource)

Manages a journal rule, which sends a copy of the matching messages to an archive outside Exchange Online (`New-JournalRule`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `journal_email_address` is required to create a rule. Set `transport_config.journaling_report_ndr_to` first: Exchange Online sends the journal reports it cannot deliver there.

## Example Usage

```terraform
# Journal reports that cannot be delivered go to this address, required first.
resource "msexchangeonline_transport_config" "this" {
  journaling_report_ndr_to = "journal-ndr@archive.contoso.com"
}

# Journal the messages of every recipient to an external archiving service.
resource "msexchangeonline_journal_rule" "archive" {
  name                  = "Archive all mail"
  journal_email_address = "journal@archive.contoso.com"
  scope                 = "Global"
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `enabled` (Boolean) Whether the rule is enabled.
- `journal_email_address` (String) Address that receives the journal reports: an archiving system or service outside Exchange Online, never an Exchange Online mailbox.
- `recipient` (String) SMTP address of the mailbox, contact or group whose messages are journaled. `""` journals the messages of every recipient.
- `scope` (String) Messages the rule journals: all of them, internal ones or external ones. Valid values: `Global`, `Internal`, `External` (case-insensitive).

### Read-Only

- `id` (String) The object name (same as `name`).
