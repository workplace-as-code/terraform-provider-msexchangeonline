# msexchangeonline_global_address_list (Resource)

Manages a global address list (GAL), the main address list of an address book policy (`New-GlobalAddressList`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. Manage a custom GAL for each entity of the organization; the default GAL, `Default Global Address List`, can be imported but not changed. Exchange Online cannot recalculate the members of a GAL: after a change of `recipient_filter`, a recipient enters or leaves it when its own object next changes.

## Example Usage

```terraform
# The GAL of the Contoso entity: its users, groups, rooms and contacts.
resource "msexchangeonline_global_address_list" "contoso" {
  name             = "Contoso - GAL"
  recipient_filter = "CustomAttribute1 -eq 'Contoso'"
}
```

## Recipient filter

Exchange rewrites the filter: `CustomAttribute1 -eq 'Contoso' -and Department -eq 'Sales'` comes back as `((CustomAttribute1 -eq 'Contoso') -and (Department -eq 'Sales'))`. The state keeps the configured text as long as Exchange returns the text it wrote, and shows Exchange's text when the filter was changed outside Terraform. After an import, the state holds Exchange's text: with a configuration written by hand, the first apply writes the same filter again in the configured form.

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `recipient_filter` (String) OPATH filter of the recipients in the GAL, for example `CustomAttribute1 -eq 'Contoso'`. Exchange rewrites it with parentheses: the configured text is kept as long as Exchange returns the text it wrote.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's app registration needs the global address list cmdlets of the **Address Lists** Exchange management role, which the role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes. Exchange Online does not give this role to Organization Management by default. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the GAL name:

```terraform
import {
  to = msexchangeonline_global_address_list.contoso
  id = "Contoso - GAL"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_global_address_list.contoso
  identity = { id = "Contoso - GAL" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_global_address_list.contoso "Contoso - GAL"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
