# msexchangeonline_safe_links_policy (Resource)

Manages a Defender for Office 365 Safe Links policy and its associated rule. The policy holds the URL protection settings; the rule defines which recipients it applies to. The rule exists only while one of `recipient_domain_is` or `sent_to_member_of` is set. Without one, the policy has no rule of its own and can be scoped by a standalone `msexchangeonline_safe_links_rule` resource instead: Exchange links a policy to at most one rule.

## Example Usage

```terraform
# Safe Links policy covering email, Teams, and Office apps
resource "msexchangeonline_safe_links_policy" "standard" {
  name = "Standard-SafeLinks"

  # Enable protection across all surfaces
  enable_safe_links_for_email  = true
  enable_safe_links_for_teams  = true
  enable_safe_links_for_office = true

  # Scanning behavior
  scan_urls                  = true
  deliver_message_after_scan = true

  # Click tracking and enforcement
  track_clicks        = true
  allow_click_through = false

  # Apply to internal senders too
  enable_for_internal_senders = true

  # Internal tools excluded from URL rewriting
  do_not_rewrite_urls = [
    "https://intranet.contoso.com/*",
    "https://sharepoint.contoso.com/*",
  ]

  recipient_domain_is = ["contoso.com"]
  priority            = 0
}
```

## Schema

### Required

- `name` (String) The name of the Safe Links policy. Immutable after creation.

### Optional

- `allow_click_through` (Boolean) Allow users to click through Safe Links warning pages to the original URL.
- `deliver_message_after_scan` (Boolean) Deliver the message while URL scanning completes in the background.
- `disable_url_rewrite` (Boolean) Disable URL rewriting in email (use when client compatibility issues arise). Protection still applies via API.
- `do_not_rewrite_urls` (List of String) URLs excluded from Safe Links rewriting (e.g. internal tools, trusted partners).
- `enable_for_internal_senders` (Boolean) Apply Safe Links protection to messages from internal senders.
- `enable_safe_links_for_email` (Boolean) Enable Safe Links URL protection in email messages.
- `enable_safe_links_for_office` (Boolean) Enable Safe Links URL protection in Office desktop and mobile apps.
- `enable_safe_links_for_teams` (Boolean) Enable Safe Links URL protection in Microsoft Teams messages.
- `enabled` (Boolean) Whether the associated rule is enabled.
- `except_if_recipient_domain_is` (List of String) Exclude messages sent to recipients in these domains.
- `priority` (Number) Priority of the associated rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority. Only applies when a recipient condition is set.
- `recipient_domain_is` (List of String) Apply this policy to messages sent to recipients in these domains.
- `scan_urls` (Boolean) Enable real-time URL scanning before message delivery.
- `sent_to_member_of` (List of String) Apply this policy to messages sent to members of these distribution groups.
- `track_clicks` (Boolean) Track user clicks on Safe Links-protected URLs.

### Read-Only

- `id` (String) The unique identifier of the Safe Links policy.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. The tenant needs a Microsoft Defender for Office 365 (Plan 1 or 2) license. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the exact policy name as it appears in Exchange Online:

```terraform
import {
  to = msexchangeonline_safe_links_policy.example
  id = "Policy Name"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_safe_links_policy.example
  identity = { id = "Policy Name" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_safe_links_policy.example "Policy Name"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
