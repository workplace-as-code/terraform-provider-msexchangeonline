# msexchangeonline_outbound_connector (Resource)

Manages an Exchange Online outbound connector. Outbound connectors control how Exchange Online sends email to external systems such as on-premises Exchange servers or partner organizations.

## Example Usage

```terraform
# Hybrid on-premises outbound connector
resource "msexchangeonline_outbound_connector" "onprem" {
  name           = "To On-Premises"
  enabled        = true
  connector_type = "OnPremises"

  smart_hosts  = ["mail.contoso.local"]
  tls_settings = "CertificateVerification"
  comment      = "Routes mail to on-premises Exchange for local delivery"
}

# Partner organization outbound connector with enforced TLS
resource "msexchangeonline_outbound_connector" "partner" {
  name              = "To Partner Org"
  enabled           = true
  connector_type    = "Partner"
  recipient_domains = ["partner.com"]
  tls_settings      = "DomainValidation"
  comment           = "Enforced TLS to partner.com"
}
```

## Schema

### Required

- `name` (String) The name of the outbound connector. Immutable after creation.

### Optional

- `comment` (String) Optional description of the connector.
- `connector_type` (String) The type of the connector. Valid values: `OnPremises`, `Partner`.
- `enabled` (Boolean) Whether the connector is enabled.
- `recipient_domains` (List of String) Domain names to which this connector routes messages (e.g. `contoso.com`). Required for `Partner` connectors.
- `route_all_messages_via_on_premises` (Boolean) Route all outbound internet mail through on-premises hosts.
- `smart_hosts` (List of String) Smart host FQDNs or IP addresses used to route outbound mail (e.g. `mail.contoso.local`). Typically used for `OnPremises` connectors.
- `tls_settings` (String) TLS requirement for outbound connections. Valid values: `None`, `EncryptionOnly`, `CertificateVerification`, `DomainValidation`.
- `use_mx_record` (Boolean) Use MX records instead of smart hosts to route mail.

### Read-Only

- `connector_source` (String) Read-only. How the connector was created. Values: `Default`, `HybridWizard`, `AdminUI`.
- `id` (String) The unique identifier of the outbound connector.
