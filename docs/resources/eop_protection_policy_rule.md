# msexchangeonline_eop_protection_policy_rule (Resource)

Manages the Exchange Online Protection part of a preset security policy (Standard or Strict): whether it applies, and to which recipients (`New-EOPProtectionPolicyRule`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. `name` is `Standard Preset Security Policy` or `Strict Preset Security Policy`. The rule is not created: it exists once the preset has been turned on in the Microsoft Defender portal, and the resource adopts it. Destroying the resource turns the preset off and keeps the rule. A condition left out of the configuration is not managed: set it to `[]` to clear it.

## Example Usage

```terraform
# Standard protection for a pilot group. The preset must have been turned on
# once in the Microsoft Defender portal, which creates this rule.
resource "msexchangeonline_eop_protection_policy_rule" "standard" {
  name              = "Standard Preset Security Policy"
  enabled           = true
  sent_to_member_of = ["Standard protection pilot"]
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `comments` (String) Comments about the rule.
- `enabled` (Boolean) Whether the preset security policy applies. Turning it off keeps the rule and its recipients.
- `except_if_recipient_domain_is` (List of String) Exception: the recipient's domain is one of these accepted domains.
- `except_if_sent_to` (List of String) Exception: the recipient is one of these mailboxes, mail users or contacts.
- `except_if_sent_to_member_of` (List of String) Exception: the recipient is a member of one of these groups.
- `recipient_domain_is` (List of String) Condition: the recipient's domain is one of these accepted domains.
- `sent_to` (List of String) Condition: the recipient is one of these mailboxes, mail users or contacts.
- `sent_to_member_of` (List of String) Condition: the recipient is a member of one of these groups.

### Read-Only

- `id` (String) The object name (same as `name`).
