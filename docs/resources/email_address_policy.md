# msexchangeonline_email_address_policy (Resource)

Manages an Exchange email address policy, which defines how email addresses are generated for recipients. In Exchange Online, email address policies only apply to Microsoft 365 Groups.

## Example Usage

```terraform
# Exchange Online: email address policies only apply to Microsoft 365 Groups.
# New groups get an address in the groups subdomain.
resource "msexchangeonline_email_address_policy" "groups" {
  name                            = "Microsoft 365 Groups"
  enabled_email_address_templates = ["SMTP:@groups.contoso.com"]
  priority                        = 1
}
```

## Schema

### Required

- `name` (String) Name of the email address policy.

### Optional

- `enabled_email_address_templates` (List of String) SMTP address templates (e.g. `SMTP:%g.%s@contoso.com`). The primary address uses `SMTP:` (uppercase).
- `priority` (Number) Priority of the policy. Lower numbers take precedence. The default policy always comes last and reads as `0`.

### Read-Only

- `id` (String) The unique identifier of the email address policy.

## Permissions

The provider's app registration needs the **E-Mail Address Policies** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. ## Import

Import using the policy name:

```terraform
import {
  to = msexchangeonline_email_address_policy.example
  id = "Standard Email Format"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_email_address_policy.example
  identity = { id = "Standard Email Format" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_email_address_policy.example "Standard Email Format"
```
