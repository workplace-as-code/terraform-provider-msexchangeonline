# msexchangeonline_application_access_policy (Resource)

Manages an application access policy (`New-ApplicationAccessPolicy`), which limits the mailboxes an app with Microsoft Graph application permissions (Mail.Read, Calendars.ReadWrite, ...) can access. Exchange Online only. Changes can take up to an hour to apply. Microsoft recommends RBAC for Applications for new deployments.

## Example Usage

```terraform
# The reporting app can only read the mailboxes of the Finance group.
resource "msexchangeonline_application_access_policy" "reporting" {
  app_id                = "11111111-2222-3333-4444-555555555555"
  policy_scope_group_id = "finance-mailboxes@contoso.com"
  access_right          = "RestrictAccess"
  description           = "Reporting app: Finance mailboxes only"
}
```

## Schema

### Required

- `access_right` (String) `RestrictAccess`: the app can only access the group members. `DenyAccess`: the app can access every mailbox except the group members. Changing it creates a new policy.
- `app_id` (String) Application (client) ID of the app registration. Changing it creates a new policy.
- `policy_scope_group_id` (String) Mail-enabled security group whose members the policy applies to: email address, name or object ID. Changing it creates a new policy. An imported policy reads it as the group's primary email address: use that form in the configuration, or the plan replaces the policy.

### Optional

- `description` (String) Description of the policy.

### Read-Only

- `id` (String) The policy identity, `<tenant id>\<policy id>`.

## Permissions

The provider's app registration needs the **Organization Configuration** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it. ## Import

Import using the policy identity shown by `Get-ApplicationAccessPolicy` (`<tenant id>\\<policy id>`). Set `policy_scope_group_id` in the configuration: Exchange does not return it in the form it was given.

```terraform
import {
  to = msexchangeonline_application_access_policy.example
  id = "00000000-0000-0000-0000-000000000000\\11111111-1111-1111-1111-111111111111"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_application_access_policy.example
  identity = { id = "00000000-0000-0000-0000-000000000000\\11111111-1111-1111-1111-111111111111" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_application_access_policy.example "00000000-0000-0000-0000-000000000000\\11111111-1111-1111-1111-111111111111"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
