# msexchangeonline_quarantine_global_settings (Resource)

Manages the global settings of quarantine notifications (`Set-QuarantinePolicy`): frequency, sender, languages and organization branding. This is a singleton: there is exactly one per tenant, and destroying the resource only removes it from Terraform state.

## Example Usage

```terraform
resource "msexchangeonline_quarantine_global_settings" "this" {
  notification_frequency        = "1.00:00:00"
  sender_address                = "quarantine@contoso.com"
  organization_branding_enabled = true

  languages = [
    {
      language    = "English"
      sender_name = "Contoso IT"
      subject     = "You have quarantined messages"
      disclaimer  = "Contact the Help Desk for more information."
    },
    {
      language    = "French"
      sender_name = "Service informatique Contoso"
      subject     = "Vous avez des messages en quarantaine"
      disclaimer  = "Contactez le service d'assistance pour plus d'informations."
    },
  ]
}
```

## Schema

### Optional

- `languages` (Attributes Set) Customized notifications, at most three, one element per language. An empty set removes all of them. (see [below for nested schema](#nestedatt--languages))
- `notification_frequency` (String) How often users receive quarantine notifications. Valid values: `04:00:00` (4 hours), `1.00:00:00` (1 day), `7.00:00:00` (7 days).
- `organization_branding_enabled` (Boolean) Replace the Microsoft logo with the logo of the organization theme in the Microsoft 365 admin center.
- `sender_address` (String) Address of an existing internal sender used for quarantine notifications. Empty restores the Microsoft sender.

### Read-Only

- `id` (String) Always `default`.

<a id="nestedatt--languages"></a>
### Nested Schema for `languages`

Required:

- `language` (String) Language of the notification, for example `English`, `French` or `Default`, as in `Set-QuarantinePolicy -MultiLanguageSetting`.

Optional:

- `disclaimer` (String) Text at the bottom of the notification, at most 200 characters.
- `sender_name` (String) Display name of the sender.
- `subject` (String) Subject of the notification.

The logo used by `organization_branding_enabled` comes from the organization theme in the Microsoft 365 admin center: this provider does not manage it.

## Permissions

The provider's app registration needs the **Transport Hygiene** Exchange management role. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it.
