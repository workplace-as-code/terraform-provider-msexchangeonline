# msexchangeonline_transport_rule (Resource)

Manages an Exchange transport rule (mail flow rule). At least one condition is required.

## Example Usage

```terraform
# Block executable attachments
resource "msexchangeonline_transport_rule" "block_executables" {
  name     = "Block executable attachments"
  priority = 1
  enabled  = true

  attachment_is_executable = true

  action         = "Reject"
  reject_message = "Executable attachments are not permitted by security policy."
}

# Prevent external senders from spoofing the internal domain
resource "msexchangeonline_transport_rule" "block_spoofed_domain" {
  name     = "Block spoofed internal domain"
  priority = 2
  enabled  = true

  from_address_contains = ["@contoso.com"]

  action         = "Reject"
  reject_message = "External senders cannot use internal domain addresses."
}

# Quarantine messages with social-engineering keywords in the subject
resource "msexchangeonline_transport_rule" "quarantine_suspicious_subjects" {
  name     = "Quarantine suspicious subject keywords"
  priority = 10
  enabled  = true

  subject_contains = ["invoice urgent", "wire transfer", "click here immediately"]

  action = "Quarantine"
}

# Encrypt mail sent to a partner, with the default branding template
resource "msexchangeonline_transport_rule" "encrypt_partner" {
  name    = "Encrypt mail to Fabrikam"
  enabled = true

  # A branding template only applies to mail sent from inside the organization.
  from_scope          = "InOrganization"
  sent_to_scope       = "NotInOrganization"
  recipient_domain_is = ["fabrikam.com"]

  apply_rights_protection_template               = "Encrypt"
  apply_rights_protection_customization_template = "OME Configuration"
}
```

## Schema

### Required

- `name` (String) The name of the transport rule. Changing it renames the rule in place.

### Optional

- `action` (String) The action to take when conditions are met. Valid values: `Reject`, `Quarantine`, `MoveToJmf` (deliver to the Junk Email folder). Optional when `apply_rights_protection_template` is set.
- `apply_rights_protection_customization_template` (String) Action: the branding template (`msexchangeonline_ome_configuration`) of the encrypted message, for example `OME Configuration`. Needs `apply_rights_protection_template` and `from_scope = "InOrganization"`.
- `apply_rights_protection_template` (String) Action: encrypt the message with this rights protection template, for example `Encrypt` or `Do Not Forward`, or the name of a custom template. Needs Microsoft Purview Message Encryption, and `internal_licensing_enabled = true` in `msexchangeonline_irm_configuration`: otherwise Exchange lists no template.
- `attachment_is_executable` (Boolean) Condition: an attachment contains executable content.
- `enabled` (Boolean) Whether the rule is enabled. A new rule is enabled unless this is `false`.
- `except_if_recipient_domain_is` (List of String) Exception: the recipient's domain is one of these domains.
- `from_address_contains` (List of String) Condition: the sender address contains any of these strings.
- `from_scope` (String) Condition: the sender is inside (`InOrganization`) or outside (`NotInOrganization`) the organization.
- `priority` (Number) The priority of the rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority.
- `recipient_domain_is` (List of String) Condition: the recipient's domain is one of these domains (subdomains included).
- `reject_message` (String) The rejection message shown to senders. Required when `action` is `Reject`.
- `sender_domain_is` (List of String) Condition: the sender's domain is one of these domains.
- `sent_to_scope` (String) Condition: where the recipient is. Valid values: `InOrganization`, `NotInOrganization`, `ExternalPartner`, `ExternalNonPartner`.
- `subject_contains` (List of String) Condition: the subject contains any of these words or phrases.
- `subject_or_body_contains_words` (List of String) Condition: the subject or the body contains any of these words or phrases.

### Read-Only

- `id` (String) The unique identifier of the transport rule.

## Message encryption

`apply_rights_protection_template` encrypts the matching messages with Microsoft Purview Message
Encryption (Microsoft 365 E3 or E5, Office 365 E3 or E5, or Azure Information Protection Plan 1).
`apply_rights_protection_customization_template` chooses the branding of the encrypted message: the
default template, `OME Configuration`, or a custom template (Advanced Message Encryption, E5).

## Import

Import using the exact rule name as it appears in Exchange Online:

```terraform
import {
  to = msexchangeonline_transport_rule.example
  id = "Rule Name"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_transport_rule.example
  identity = { id = "Rule Name" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_transport_rule.example "Rule Name"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
