# msexchangeonline_transport_rule (Resource)

Manages an Exchange transport rule (mail flow rule). At least one condition is required.

## Example Usage

```terraform
# Block executable attachments
resource "msexchangeonline_transport_rule" "block_executables" {
  name     = "Block executable attachments"
  priority = 1
  enabled  = true

  attachment_is_executable = true

  action         = "Reject"
  reject_message = "Executable attachments are not permitted by security policy."
}

# Prevent external senders from spoofing the internal domain
resource "msexchangeonline_transport_rule" "block_spoofed_domain" {
  name     = "Block spoofed internal domain"
  priority = 2
  enabled  = true

  from_address_contains = ["@contoso.com"]

  action         = "Reject"
  reject_message = "External senders cannot use internal domain addresses."
}

# Quarantine messages with social-engineering keywords in the subject
resource "msexchangeonline_transport_rule" "quarantine_suspicious_subjects" {
  name     = "Quarantine suspicious subject keywords"
  priority = 10
  enabled  = true

  subject_contains = ["invoice urgent", "wire transfer", "click here immediately"]

  action = "Quarantine"
}
```

## Schema

### Required

- `action` (String) The action to take when conditions are met. Valid values: `Reject`, `Quarantine`, `MoveToJmf` (deliver to the Junk Email folder).
- `name` (String) The name of the transport rule. Changing it renames the rule in place.

### Optional

- `attachment_is_executable` (Boolean) Condition: an attachment contains executable content.
- `enabled` (Boolean) Whether the rule is enabled. A new rule is enabled unless this is `false`.
- `from_address_contains` (List of String) Condition: the sender address contains any of these strings.
- `priority` (Number) The priority of the rule. Lower numbers are evaluated first. When omitted, Exchange assigns the lowest priority.
- `reject_message` (String) The rejection message shown to senders. Required when `action` is `Reject`.
- `subject_contains` (List of String) Condition: the subject contains any of these words or phrases.

### Read-Only

- `id` (String) The unique identifier of the transport rule.
