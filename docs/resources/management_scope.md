# msexchangeonline_management_scope (Resource)

Manages a management scope: the recipients a role assignment can change, selected by an OPATH filter (`New-ManagementScope`). Attributes left out of the configuration take the Exchange default when the object is created and are not managed afterwards. Use it in `msexchangeonline_management_role_assignment` (`custom_recipient_write_scope`, or `custom_resource_scope` for an application).

## Example Usage

```terraform
# The recipients of the French subsidiary
resource "msexchangeonline_management_scope" "france" {
  name                         = "France"
  recipient_restriction_filter = "CustomAttribute1 -eq 'France'"
}
```

## Schema

### Required

- `name` (String) The name. Changing it creates a new object.

### Optional

- `exclusive` (Boolean) An exclusive scope: only the assignments that use it can change its recipients, even for administrators with organization-wide roles. Changing it creates a new scope.
- `recipient_restriction_filter` (String) OPATH filter of the recipients in the scope, for example `CustomAttribute1 -eq 'France'`. Exchange may rewrite it with parentheses: the configured text is kept as long as Exchange returns the text it wrote.
- `recipient_root` (String) Organizational unit the filter applies to. Empty for the whole organization.

### Read-Only

- `id` (String) The object name (same as `name`).

## Permissions

The provider's app registration needs the **Role Management** Exchange management role, which lets it grant itself any other role: give it only to the pipeline that manages the Exchange delegation. The role group created by [`tools/new_role_group.ps1`](https://github.com/workplace-as-code/terraform-provider-msexchangeonline/blob/main/tools/new_role_group.ps1) includes it with `-IncludeRoleManagement`. See the [Authentication guide](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/authentication).

## Import

Import using the scope name:

```terraform
import {
  to = msexchangeonline_management_scope.france
  id = "France"
}
```

Or by identity (Terraform 1.12 and later):

```terraform
import {
  to       = msexchangeonline_management_scope.france
  identity = { id = "France" }
}
```

Or with the CLI:

```shell
terraform import msexchangeonline_management_scope.france "France"
```

To import every existing object at once, see [Import an existing tenant](https://registry.terraform.io/providers/workplace-as-code/msexchangeonline/latest/docs/guides/import_existing).
